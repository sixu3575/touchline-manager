# Fixtures 界面模块

场景版由PressRoom组合体育报/电视/录像档案；Fixtures分为联赛、赛历、城市杯和荣誉四版，完整积分收进details，不丢近三场/名次变化/下一轮。PlayerLeaders保留原接口与排序，仅增加可聚焦滚动区域；MyMatches录像标签开MatchReport、播放开Replay，权限不变。见docs/IMMERSIVE_UI.md。

新增独立“联赛球员榜”页面，读取`/api/league-player-leaders`的本赛季联赛汇总；不含杯赛、未结算比赛或对手回放入口。详情由同存档战报归档一次批量聚合，覆盖场次与单项统计覆盖数会显示，缺失旧数据不伪记为零。榜单含进球、助攻、出场、射门/xG、传球、抢断、拦截、过人、门将扑救/零封、牌数等常见比赛统计。只读展示，不修改比赛/球员状态或存档结构。
