# matches 界面记录

## 2026-10-16 · 0.2.0

将原实现移入独立模块目录，保留原导入路径的兼容入口，减少多人修改主界面的冲突；原战术/回放交互和存档事件来源不变。验证类型、构建及真实页面导航。

## 0.3.0 · 2026-10-16

增加实际轨迹Canvas回放、球高阴影、插值、暂停/变速/时间轴/下一射门、球员跑动统计和轨迹加载重试。旧报告继续LegacyReplay，静态阵型移除假摆动；手机统计单列，滚动时关闭栏保持可见；桌面/手机与公网浏览器验证。

## 0.4.0 · 2026-10-16

回放新增关键/裁判/全部动作筛选、动作质量解释、纪律与心理统计、红牌时间点隐藏、物理点球阶段时钟；比分独立于筛选器计算，旧回放格式兼容。

验证：沿用npm run check；新增approved-v1规则/迁移/确定性测试，发布另做浏览器与VM验证。

## 0.5.0 · 2026-10-16

回放默认1×实速，新增轨迹球速（cut重开不计算）、球风、带球/直塞/长传/一脚出球及决策理由；兼容旧报告缺少新增字段。

验证：新增player-intelligence场景/物理回归，沿用npm run check、PR和VM/浏览器检查。

## 0.6.0 · 2026-10-17

新增useMatchJob/MatchTask，SSE重连与序号补片，实时画面12×默认、生成/观看双进度、缓冲/暂停/跟随最新/已生成历史进度和后台切换。PhysicalReplay兼容传入进行中轨迹；比分/事件按播放时间，统计只使用不晚于播放时刻的阶段快照并标记时间，避免全场剧透。后台结束可完整拖动/调速/射门跳转。注意客户端仅插值，不能补算物理或把已完成画面描述成仍在计算；旧报告继续原解码。

验证：沿用npm run check；新增有限接球、跨中场检查点、任务去重/重启/隔离和完整赛季验证；另做100场分层校准、VM受限内存和桌面/窄屏验证。结果以发布记录为准。
历史回放补充：Replay按需读取压缩战报详情，保留旧报告直接打开；加载失败可重试。任务切换时分段缓存绑定具体任务，旧请求不能覆盖新任务片段。
