# 实时观看修补 · 2026-10-20

生产诊断时轨迹生成领先播放约十分钟，仍出现卡顿；原直播progress报告约7MB，随后私有离线样本增长到9.4MB。旧服务cgroup MemoryPeak触及512MiB，memory.events.max曾记录111次，未见OOM kill。不能把这种卡顿归因于球员决策速度，也不能用短场生成速度代替长场观看验收。

## 修改

- 私有work/checkpoint与正式归档保留完整内容；progress.report仅存清理诊断后的展示副本。只读缓存最多2项，以原JSON变化失效，失败数据库时钟写入不修改缓存。观赛查询不取work BLOB，帧请求不构造完整报告。
- 画布读取连续ref时钟，仍逐帧插值；React面板每100ms同步，报告替换不重建画布动画循环。5×与服务器UTC不改。最终摘要先到而帧未到齐时，画面不提前终场；比分和统计依照已看到的时间。
- 球员面板新增进球、助攻、射门/射正、扑救、拦截、关键传球、犯规和越位，另展示已有抢断成功/尝试。服务器保留全部已发生的统计相关事件，普通动作仍只保留120条尾部；浏览器按画面时间再截断。
- 射正来自shotOutcome.onTarget，助攻来自非乌龙goal.assistId；点球大战与常规射门分开，重复shotId不重复计数。统计版本缺失且无确认事件的旧档显示“—”，不能只凭eventFormatVersion猜测完整证据。
