# 球员界面变更记录

## 0.13.0 · 2026-10-19

0.13.0后续展示调整：取消评估综合，公开服务端按原位置评级计算的实际总能力值overall；一线队同一列展示总能力与六维雷达图，默认按总能力降序，各表头可切换升降序（出场/进球分列）。细项按六项主属性归类，外场门将专项/门将其他进攻技术折叠补充，并明确不计入对应概览；30项各出现一次。分组不改变汇总权重或比赛算法，细项区间及教练/球探机制保留，自动排阵继续使用已知区间。

能力区间/卡片本就整数，现将百分制状态条文字统一取整；10分制表现/评分保持原样，旧历史展示通过服务端整数评估。

## 0.12.0 · 2026-10-19

六项卡片、细项区间/待观察、评估综合、团队升级与派遣观察；模型不再包含真实attributes，潜力/逆足显示区间，模板不发浏览器。桌面/窄屏检查与类型构建。

## 0.11.0 · 2026-10-19

Player模型可选attributeProfile；详情身份区显示技术模板/观察球员，旧档缺字段继续正常展示。模板没有额外竞技加成。

## 2026-10-16 · 0.2.0

从主界面拆出一线队、球探和档案；新增国籍、惯用脚、生日、身高、30 项能力、性格与生活页签；名单显示平均年龄、国家数量和士气。档案支持 Escape 关闭和焦点循环，宽窄屏布局独立维护。

注意：主入口通过导出调用此目录，球员样式写入 players.css，避免修改全站样式产生冲突。无交互和粉丝收入功能时不展示相应操作按钮。

## 0.4.0 · 2026-10-16

球员详情展示适应度，说明士气/信心/适应只小幅影响镇定与决策；旧快照缺值展示100。

验证：沿用npm run check；新增approved-v1规则/迁移/确定性测试，发布另做浏览器与VM验证。
