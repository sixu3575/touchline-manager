# 球员界面变更记录

## 0.11.0 · 2026-10-19

Player模型可选attributeProfile；详情身份区显示技术模板/观察球员，旧档缺字段继续正常展示。模板没有额外竞技加成。

## 2026-10-16 · 0.2.0

从主界面拆出一线队、球探和档案；新增国籍、惯用脚、生日、身高、30 项能力、性格与生活页签；名单显示平均年龄、国家数量和士气。档案支持 Escape 关闭和焦点循环，宽窄屏布局独立维护。

注意：主入口通过导出调用此目录，球员样式写入 players.css，避免修改全站样式产生冲突。无交互和粉丝收入功能时不展示相应操作按钮。

## 0.4.0 · 2026-10-16

球员详情展示适应度，说明士气/信心/适应只小幅影响镇定与决策；旧快照缺值展示100。

验证：沿用npm run check；新增approved-v1规则/迁移/确定性测试，发布另做浏览器与VM验证。
