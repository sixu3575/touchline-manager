# 球员技术特点与一次重塑（0.11.0）

0.13.0覆盖下文0.11.0的小数精度：新生成/重塑输出整数，通过整数微调匹配已取整预算；现有球员本次仅四舍五入不重新分配，单项差≤0.5。当前规则见[INTEGER_STATS.md](INTEGER_STATS.md)，下文旧重塑/预算误差描述保留为历史。

profiles.mjs只负责赛前能力分配，index.mjs公开reprofilePlayer与observationPlayer。能力仍为1–100、最多一位小数，六项skills由attributes派生，原评级和比赛计算公式保持。

新球员先确定位置预算，再选择位置允许的技术偏向：后卫有强硬防守/出球/边路往返，中场有组织/扫荡/跑动/速度突破，前锋有抢点/支点/突破/串联，门将有反应/出击出球/制空。相关潜变量让速度与灵活、力量与头球、技术与停球、意识与预判产生趋势联系，再加入单项差异，避免每一项一起高或各组同值。不是每个标签都保证所有相关能力最高。身高只小幅影响头球/力量分布，国籍不参与。

六个评级预算通过有界加权投影保留；旧档重塑按存档seed+player.id独立确定，六项摘要误差≤0.1，综合舍入最多约1点变化。原身份、年龄、性格、训练后的六项总预算、体能、心理、生涯、价格和工资保留；具体细项按本次用户授权重新分配。历史报告快照与轨迹不修改。attributeProfile={version:1,archetype,source}为可选说明；版本标记确保第二次维护不重抽，以后的训练正常改变细项。

技术模板是数值来源说明，比赛球风依旧由实际属性生成，没有隐藏技能加成。更强盘带会进入原来的持球/一对一估计，传中与头球分别影响出球和接应，决策影响候选误差；详见比赛模块的PLAYER_DECISION_MAP。高能力不等于固定高比分。

观察球员：林曜，99号、中国、24岁（2026游戏日期），双脚、188cm，综合95。终结98、无球98、停球97、镇定97、决策96、盘带96、头球95、冲刺92、耐力96；盯人35、抢断38、门将能力低。由显式离线维护只加入指定用户存档，以中锋替换一个首发槽位，原球员留队，阵型/战术保持。免费指转会价格£0，轮薪依综合能力按通用工资公式计算（综合95为£1,800/轮）；不为所有新游戏生成，不给赛果/评分特殊待遇。playerProfileGrant标记防止出售后再次发放。

维护入口与保护见根docs/OPERATIONS.md；只能在无未完成比赛、有一致离机备份且服务停止时执行。JSON/SQLite仍3，不修改启动迁移、HTTP动作、赛历或结算流程。进一步调整开发流程仍须用户批准。
