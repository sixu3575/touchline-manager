# 球员模块变更记录

## 0.12.0 · 2026-10-19

新增assessment.mjs的公开六项、稳定区间、教练/球探等级和观察规则；真实30项/旧skills不变。新增接入审计与搁置清单。7组针对性检查及完整业务赛季；没有物理算法变化。

## 0.11.0 · 2026-10-19

新增profiles.mjs的13种位置允许技术偏向、相关潜变量与单项差异，index.mjs公开reprofilePlayer/observationPlayer。attributes仍唯一竞技来源，技能预算投影使旧档六项误差≤0.1/综合最多约1点。一次版本标记防止刷新或训练时重抽；原身份、体能、人格、经济和历史不动。观察前锋综合95，正常进入原比赛/评分。5组生成、预算、事务/幂等与安全边界测试；默认能力变化执行真实比赛专项，不改变赛历/结算或开发流程。

## 2026-10-17 · 球员业务测试解耦

- 生日直接准备换季边界，保留年龄、时间推进与身份断言；训练/性格/迁移使用测试进程显式提供的受控赛果，避免准备状态时隐含计算真实比赛。
- 实际有效能力/跑动/决策仍由比赛专项验证；相关默认数据与源码变化核对决策参考摘要。生产球员模型、能力和训练公式未改，规则见docs/VALIDATION.md。

## 2026-10-16 · 比赛影响设计（待审批）

- 适应度字段、心理影响和新引擎均未实现；保留当前 0.2.0 数据和训练行为。新增注意事项：设计稿不是已启用规则，必须先取得用户批准。

## 2026-10-16 · 0.2.0

- 新增身份、细分能力、性格、生活兴趣和近期状态；按生日计算年龄；年龄/职业态度影响成长；提供旧档补全接口。
- 明确与其他模块的调用边界和唯一文件归属。
- 验证：完整赛季、确定性、资金、API 并发、存档持久化和备份恢复；模块依赖检查纳入现有测试。
- 注意：球员字段新增和变更优先在本目录实现；客户端对应 packages/client/src/modules/players。skills 是 attributes 的派生兼容缓存，改变细项后必须刷新；不能让其他模块直接修改球员能力、性格或状态。旧回放允许只有六项 skills，rating 必须保留兼容。国籍不参与能力计算。

## 0.3.0 · 2026-10-16

settlePlayerMatch接受可选赛末energy；物理比赛使用真实跑动消耗的体能，缺省保留旧结算兼容。人格不加新隐藏赛果权重；后续恢复仍由赛程调用公共API。

验证：沿用npm run check；新增approved-v1规则/迁移/确定性测试，发布另做浏览器与VM验证。
