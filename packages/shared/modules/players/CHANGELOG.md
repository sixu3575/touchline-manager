# 球员模块变更记录

## 0.30.0 · 比赛持续体能校准

`energyCost`持续消耗基准系数从0.32升至0.64，按真实运动强度、压迫、位置和活/死球状态耗能；力量/耐力决定容量和经济性逻辑不变。四战术×两种子诊断中，外场球员平均终场体能由85.05降至63.79，冲刺距离更接近UEFA精英赛事锚点且总跑动/高速距离大致不变。该校准随比赛模块0.35.0、PR #49于2026-10-24部署。对照与限制见matches/design/MATCH_FATIGUE_CALIBRATION_V0350.md；历史结果/fitness不重算，不改存档结构。

## 0.29.0 · 2026-10-21 · 个体体能与按天恢复

新增physiology纯模型，力量/耐力决定持续容量、经济性、短时储备与恢复、紧急爆发时长/债务及轮间恢复。0–100体能允许耗至0，recoverPlayer的第二参数改为经过天数而不是点数；指数恢复替代固定加8，旧球员/能力/历史不重塑。场中恢复不超过原赛前状态。完整公式见matches/design/PHYSIOLOGY_V0290.md；属性审计/决策图同步，验证及部署见PR，不改流程。
