# 比赛模块变更记录

## 0.6.1 · 2026-10-17

- 检查属性/体能到实际刚体跑速，提取driveMovement执行有限加减速；每子步增加个人冲刺+0.6m/s异常碰撞保护。
- 修复固定Rapier自转上限使球持续打滑、草地过度减速；法向碰撞保留，切向改显式阻力。增加三维二次空阻、地面平移/旋转耗能和38m/s主动触球保护，正常慢滚可停至零。
- ball-motion统一地面传球力度/到达时间与接球预测，高球/射门近似补偿空阻。引擎0.6.1-physical-motion，参数physical-motion-1，旧回放不重算。
- 动作解释记录实际施加冲量后的速度，避免将限速前的请求值误标成实际球速。
- 新增实际刚体属性差异、有限转身、超速保护、减速/停止、空阻/反弹、传球到达和有限触球验证；沿用npm run check、PR和上线验收，结果见发布记录。数学/来源/旋转简化和恢复注意事项见design/PHYSICAL_MOTION_V061.md。CI仅按用户另行批准的两项调整，范围见根AGENTS，其余流程不变。

## 0.3.0 · 2026-10-16

重做为Rapier3D固定步长物理：球/球员/门框碰撞、实际触球冲量、战术AI、头球与门将处理、门线判定、轨迹与跑动统计。分离physics/agents/simulation，旧提案标注历史状态；物理与种子复现测试、完整赛季/API验证，公式见design/PHYSICAL_ENGINE_V1.md。免费VM使用720秒物理/90分钟游戏时钟；步长20Hz不变，实际模拟距离不折算冒充90分钟里程。

统一双方球员结算入口settleClubPlayers，修复旧系统只扣本队体能而AI永远满体能的问题；不向AI发放本队资金，确保没有重复结算。

公式复核修正追球预判的方向：高预判球员提前迎向未来落点，测试锁定此属性影响。

进球后保留2.5秒自然入网/反弹轨迹，再进入中圈重开；避免5Hz回放采样直接跳过门线后的轨迹。新增对应物理回放测试。

## 0.4.0 · 2026-10-16

实施已批准A/B/C并保留真实Rapier球轨迹。新增rules及shootout，分层动作质量、越位、近身犯规、纪律、自由球/点球、物理点球大战和助攻解释；退场不得再运动/碰撞。旧事件和轨迹不可重算。数学和简化边界见design/APPROVED_V1_PHYSICAL.md。

验证：沿用npm run check；新增approved-v1规则/迁移/确定性测试，发布另做浏览器与VM验证。

## 0.5.0 · 2026-10-16

修复球撞自身/传感器滞后一帧；分离躯干/腿、有限抬脚与滚动角冲量。新增spatial/skills/locomotion/positioning/decisions，agents保留内部兼容导出。实现步行/慢跑/补位/冲刺/带球、角色职责、持续带球意图、球风与空间/拦截时间决策；防止过期意图和门将慢球死锁。新增motion/行为统计，不重算旧回放。

接球职责3.5秒后回到就近争球，避免传球落空后近处队友等待；传后前插在球飞行期间也执行加速。

验证：新增player-intelligence场景/物理回归，含过期接球职责和传后前插，沿用npm run check、PR和VM/浏览器检查。
