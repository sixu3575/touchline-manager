## 0.3.0 · 2026-10-16

重做为Rapier3D固定步长物理：球/球员/门框碰撞、实际触球冲量、战术AI、头球与门将处理、门线判定、轨迹与跑动统计。分离physics/agents/simulation，旧提案标注历史状态；物理与种子复现测试、完整赛季/API验证，公式见design/PHYSICAL_ENGINE_V1.md。免费VM使用720秒物理/90分钟游戏时钟；步长20Hz不变，实际模拟距离不折算冒充90分钟里程。

统一双方球员结算入口settleClubPlayers，修复旧系统只扣本队体能而AI永远满体能的问题；不向AI发放本队资金，确保没有重复结算。

公式复核修正追球预判的方向：高预判球员提前迎向未来落点，测试锁定此属性影响。

进球后保留2.5秒自然入网/反弹轨迹，再进入中圈重开；避免5Hz回放采样直接跳过门线后的轨迹。新增对应物理回放测试。

## 0.4.0 · 2026-10-16

实施已批准A/B/C并保留真实Rapier球轨迹。新增rules及shootout，分层动作质量、越位、近身犯规、纪律、自由球/点球、物理点球大战和助攻解释；退场不得再运动/碰撞。旧事件和轨迹不可重算。数学和简化边界见design/APPROVED_V1_PHYSICAL.md。

验证：沿用npm run check；新增approved-v1规则/迁移/确定性测试，发布另做浏览器与VM验证。

## 0.5.0 · 2026-10-16
