# 赛后评分记录

## 0.30.1 · 首发球队评分

新增两队首发11人均分，完整证据不足不计算；withPlayerRatings保留既有个人评分并只附加teamRatings，旧BLOB读取只增响应。未改个人评分、运动或结算，专项不计算比赛/赛季。说明见TEAM_RATING_V0301.md。

## 0.30.2 · 首发平均能力值

联赛球队数值改为按本场存档首发的实际总能力求整数均值，与赛后表现评分分开；不满11人或能力证据不全则显示未记录。服务端摘要从历史完整快照生成只读聚合，不暴露细项、不改旧评分/比赛/赛季。规则见[TEAM_ABILITY_V0302.md](TEAM_ABILITY_V0302.md)。

普通带球距离沿用原有最多0.25分的贡献，新增加分来自真实成功过人，避免只靠里程或触球数量抬高评分。

直播计数按同一时刻的快照加后续增量传输，避免每次重复整场历史；若浏览器尚落后于基线则显示未知，不能预先显示未来计数。归档事件保持完整。
