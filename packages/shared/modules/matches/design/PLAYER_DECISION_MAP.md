# 球员决策树：触发数值、概率与属性实战效果

0.30.1另提供[首发球队均分](../ratings/TEAM_RATING_V0301.md)：只对本场11名首发的已保存个人评分做算术平均，不回写个人评分，不参与球员决策或物理；七张决策图/SVG分支保持，ratings入口源码摘要随只读汇总更新。

当前已部署引擎`0.46.0-carry-routes` / `carry-routes-1`，完善多人带球路线风险，保留远射窗口比较，设计和实测见[远射窗口](SHOT_WINDOWS_V0450.md)。在0.41战术身份与0.42防守协同基础上，反击增加合法压线跑位、近距离地面直塞和更深身后过顶球候选；速度/无球意识影响跑位深度，视野/传球/决策影响送球价值。防守者会随球补位、跟踪危险跑位并按压迫/协同能力围抢；额外围抢者会离开盯人池形成漏防风险。跑位保持在传球瞬间的越位线后，候选还要通过线路、接球竞速及真实球速/阻力；所有动作仍相互比较，不设传球配额或强制结果。完整比赛校准与样本限制见[反击跑位复核](COUNTER_RUNS_V0430.md)、[防守协同复核](DEFENSIVE_COORDINATION_V0420.md)和[战术身份校准](TACTICAL_IDENTITY_V0410.md)。体能按实际位移、冲刺启动和真实身体接触累计；耐力/力量影响容量、能耗经济和赛后按天恢复，高负荷与低负荷球员消耗不同。赛后40–50到下场前80多是校准目标，由真实负荷和属性形成，不把终场体能强制写成固定值。完整公式见[个人工作量体能设计](MATCH_WORKLOAD_V0400.md)。历史比赛不重算。

绿色是候选成功**估计**，橙色是实际随机**抽签**，其余是条件、价值修正或物理执行。估计80%不等于系统抽签直接判传球成功；进球仍须实际球越线。下文列相关性、因素和触发参数，具体公式只放专项数学文档。

F3/F4球风倾向在开赛缓存，不随每次疲劳或心理波动重算；实际跑速、动作质量仍使用实时有效能力。组织组三项均值比推进组高35点时倾向达到组织端，反之达到推进端；评分是倾向修正而非概率。回传也会受到该球风传球修正，只是幅度较小。标签“回撤接应前锋”不会单独启用回撤算法，“防守后卫”不禁止带球，推进标签也不直接增加冲刺速度。

FG/FB是赛前数值分配，不是新的赛内抽签。服务器技术模板只解释数值来源（0.12.0不再直接披露给客户端），不给予隐藏加成；如速度突破型更偏盘带/灵活/传中，支点型更偏头球/力量，组织型更偏视野/停球，仍逐项经过第1～5图的实际能力与局面判断。旧档六项预算保持在0.1点误差内，最多约1点综合舍入变化；新增球员按位置预算随机生成。99号观察球员林曜只显式加入指定存档，终结98/无球98/决策96/盘带96，防守与门将能力仍低；没有强制进球、胜利或评分加成。来源：[profiles.mjs](../../players/profiles.mjs)、[球员公共接口](../../players/index.mjs)。

位置和战术仍有实际差别：前锋传后前插优先、射门评分加0.006；后卫后场带球视走廊危险减0.02～0.07并承担盯人；中场和后卫更常被选支援；门将使用手部、守门站位及出球逻辑。控球更偏安全传球，反击更偏向前和快速转移，边路拉宽并允许特定区域传中；高/中/低压迫改变追球人数、阵形与耗能。4-3-3两侧前锋锚点可进入边路标签，而4-4-2/3-5-2的两名前锋通常不会，仅标签不同不等于多出一套行为。
