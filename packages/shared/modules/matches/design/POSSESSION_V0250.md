# 0.25.0 按盘带能力调整带球触球

状态：待发布候选。目标是减少球员带球触球后球持续跑到身前、跟球衔接不上而失控的情况。它只调整带球触球冲量，不改变传球/盘带/射门候选的选择权重、球员无球跑速、地面球阻力、实际脚触碰撞体、争抢概率或控球宽限。

## 触球模型

球员已有跑速在带球方向上的分量作为触球基准。额外前送量随盘带能力下降：

| 盘带能力 | 快带额外前送 | 近控额外前送 |
| ---: | ---: | ---: |
| 1 | 0.396 m/s | 0.346 m/s |
| 50 | 0.200 m/s | 0.150 m/s |
| 100 | 0.000 m/s | -0.050 m/s |

起步球速仍不低于2.2 m/s；快带和近控的最终球速分别不超过球员当前档位跑速再加1.6m/s和0.65m/s。盘带值100时近控额外量虽为-0.05m/s，但起步下限和移动速度上限仍控制最终结果。球员本身的速度仍由速度、体能与运动档决定。

该关系令低盘带球员更容易把球推离身体，高盘带球员可以把触球留在更好跟进的位置。它不直接替球员选择突破，也不会因盘带高而保证成功过人。下一次控球/传射仍须发生真实有限脚触；球独立运动并受现有草地摩擦减速。

## 同输入八场对照

固定世界42、四种战术、种子999/1001；对照基线0.20.0，均为普通生成球队。报告在忽略目录`work/validation/calibration-0.25.0-possession-touch/`，不进入Git。

| 指标 | 0.20.0 | 0.25.0 | 变化 |
| --- | ---: | ---: | ---: |
| 八场每场团队控球阶段中位数的均值 | 5.06秒 | 5.29秒 | +0.23秒 |
| 所有阶段中短于5秒的加权占比 | 49.36% | 47.99% | -1.37个百分点 |
| 平均P90阶段长度 | 14.84秒 | 16.64秒 | +1.81秒 |
| 成功传球链均值 | 1.76 | 2.12 | +20.9% |
| 每场两队传球总数 | 664.75 | 806.5 | +21.3% |
| 成功传球率 | 70.40% | 70.92% | +0.52个百分点 |
| 带球脱控 `looseCarry` | 191.38 | 118.00 | -38.4% |
| 被对手真实控制结束的个人控球 | 94.50 | 90.13 | -4.6% |
| 拦截 | 102.25 | 112.00 | +9.5% |
| 总射门 / 总进球 | 24.00 / 2.875 | 23.25 / 2.25 | 没有增加 |

八场全部为`review`，没有`block`。跑动最低为4,069米/90分钟，略高于4,000米的工程阻断线；其他review仍需按全局现实性契约解释。传球、成功链和带球脱控有明确改善，但阶段中位数仍约5秒、约48%短于5秒，所以本候选**没有解决**控球中位数问题。诊断也显示控球阶段结尾以真实拦截、被夺球和球员跟球失控为主，不适合通过延长计时器伪造持球。

新增后台汇总把短于5秒的阶段按终止原因和阶段内成功传球数拆分；该字段位于`replayAnalysis`，由玩家出站视图剔除。八场共1,680个短阶段：1,260个没有成功传球（75.0%），404个有1次（24.0%），16个有2次（1.0%），没有3次以上。终止原因为拦截546次、被断540次、失控333次；其中拦截与被断占64.6%，失控占19.8%。这说明阶段中位数仍短，主要发生在首次传递/持球建立之前，而不是长传球链中断。它用于后续核查实际抢断接触、传球线路可达性和跟球失控；不构成玩家统计，也不会反过来改变决策。

## 已比较并撤回的方向

- 让所有接应球员更靠近持球人，八场中位数降到约5.12秒，传球均值和传球链也略降；多名球员跑动跌破4,000米并触发`block`。不能以堆叠近端接应人为拉高保球。
- 把地滚球速度整体调快约0.55m/s，八场中位数降至约5.19秒、射门均值升至26.5次/场。球更快不代表控球更长，且进攻样本进一步提速，已撤回。
- 限制脚部每帧对球的转向，八场中位数约5.06秒、传球与链长减少，多人跑动低于4,000米并触发`block`。瞬时脚部朝向值得继续建模，但该版本不能发布。

这些一次性尝试结果留在本地忽略目录`work/validation/`，没有进入生产参数或决策树。后续节奏工作应使用新增短阶段分布来定位实际结束方式，再选一个物理原因改动并复测；不设控球配额，不改合理传带射偏好，不把5秒中位数当单独校准目标。
