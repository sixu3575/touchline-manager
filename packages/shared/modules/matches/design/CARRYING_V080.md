# 0.8.0：利用空地推进与有选择的突破

用户反馈：无人盯防也偏向传球，盘带等能力的实战作用不足。本次改变候选排序和带球路线，版本`0.8.0-carrying` / `carrying-1`。未改球速、摩擦、身体上限、接触半径、抢断抽签或观看时钟。旧报告/轨迹不重算；上线前排空旧引擎任务。

## 行为与归属

- `carrying.mjs`集中生成带球路线与机会估计；`decisions.mjs`比较传/带/射并生成触球冲量；`simulation.mjs`保留真实接触/对抗，记录`intent:takeOn`与突破理由，依旧统计dribbleTouches/carryDistance。
- 空旷前路有独立推进收益，不再只有长距离传给队友才有场地价值。传球保留收益缩小，无压力时不因控球一秒就额外催促出球；明显进攻接应有穿透收益，优于盲目带球。
- 左中右扩成横向−6/−3/0/+3/+6米五路；有效未到达目的地也参与候选，但每次都复查新路线，不能被原意图锁住。到达旧目标后继续寻找前方空间。
- 单防估计比较己方盘带质量、带球速度与具体防守者能力；协防同时增加风险和评分代价。身后较远的追兵不会被当成正前方封堵，转身逃离仍由真实接触与移动限制。
- `takeOn`只是本次路线面对拦挡时的意图，actor.intent仍为carry，保持原移动、控制与检查点编码。没有新增隐藏盘带天赋、自动过人或成功率抽签。

## 当前数学（候选评分，不直接判定成败）

所有能力使用赛内有效值1～100；`q`沿用65%盘带、20%灵活、15%平衡，再考虑脚侧、压力与专注失误；`V`沿用pitchValue。`clip`表示限幅。

1. 路线纵向目标距离`L=6+0.035×无球跑动`米，横向五路并轻微回中，仍限制在x∈[1,104]、z∈[2,66]；向前不足0.5米的路线不参与。复用目的地须距球>2米、仍向前>1米，意图未过期；五条新路线始终重新比较。
2. 对手投影到路线的纵向距离须在−0.5至路线长度+3.5米，最近走廊距离截到12米。危险度`d=clip((2.8-near)/2.8,0,1)`；除最近者外，走廊6米内最多两名对手记协防数`c`。这是一轮短距离路线近似，未用无限视野或直接判断过人成功。
3. 防守质量`D=0.55×抢断+0.25×防守站位+0.20×平衡`；门将改为55%单刀、25%反应、20%平衡。速度差为本人carry档减对手run档，维持原物理速度公式。个人突破估计`u=clip(0.5+0.006(q-D)+0.025×速度差,0.12,0.88)`。
4. 路线保球估计`s=clip(0.97-d(1-u)-0.14c,0.12,0.98)`。空旷无协防的基础值97%；不是取随机数直接判成功。`d>0.15`才标为takeOn，约对应对手距走廊<2.38米。
5. 空间奖励`B=0.08×clip((near-2.5)/6,0,1)×clip(纵向推进/8,0,1)`。盘带候选收益为`sV(目标)-V(当前)-(1-s)(0.09+0.4V(当前))+B+0.045×球风倾向+0.1d×max(0,u-0.45)/(1+c)+持续奖励-0.035c-本方风险-边线风险+进取心`。
6. 持续奖励0.035，只给有效旧目的地；本方35米内的后卫风险为`0.02+0.05d`（空地0.02、最危险0.07），其他角色为0；边线风险仍最多0.03；末段落后进取心仍最多±0.02。球风、空间、单防和协防分别作用，不能通过堆盘带属性忽略多人夹击。
7. 传球保留收益变为`0.008s+0.003×min(3,接应点数)+0.012×压力×min(1,持球秒数)`，替代原无条件较高奖励。进攻穿透奖励为`0.035s×clip((向前距离-10)/12,0,1)×clip((目标纵向位置-70)/20,0,1)`；用于保留更好的禁区前沿/身后队友机会，不给普通无效横传同样奖励。控球/反击/传中战术、解围和射门评分沿用。
8. 决策扰动半幅仍`0.006+0.045×(1-有效决策/100)`。每次传/带/射三类分别抽一次，同类路线共享扰动，传中归传球类；先按实际机会比较同类候选，避免十几个传球选项获得额外随机优势。它不是按评分比例抽动作，也没有固定传带占比。

## 执行与属性效果

盘带提高保球质量、本人carry速度、短触精度与频率，并改善既有被抢对抗；灵活/平衡辅助质量和转向/刹车；冲刺改变本人和对方的速度差。对手抢断/站位/平衡直接进入本次估计；原近身抢断仍使用既有真实对抗。无球跑动影响推进目标，视野/传球/决策仍影响出球机会与稳定选择。门将和定位球继续禁止普通带球，临门射门与好传球仍可胜出。

## 验证与数据解读

新增确定性决策场景：双方向无人区推进、单改盘带/改变对手强度、单防与协防、保留好传球和射门、旧目标到达后续推。保留原物理、动作解释和球风差异断言，最终按已批准分层规则跑真实比赛专项；不涉及赛历或结算，无完整赛季触发。

同初始世界、同种子2026/999，各900秒的真实物理对照（不是fixture）：旧传球合计315次、新238次；旧带球触球35次、新157次；旧带球距离593米、新796米；新记录6次takeOn。只是两段小样本，作为方向核对，不代表整场固定比例。carryDistance还包括建立控制后的移动，takeOn是挑战意图，不能当成功过人数。完整比赛/确定性/worker恢复/HTTP和上线证据见发布记录。
