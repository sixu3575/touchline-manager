# 胸/大腿卸球、禁区上抢、传球执行估计与战术体检（0.50.0-body-trap）

承接[0.49修正](REALISM_FIXES_V0490.md)，95场汇总见[REALISM_FIXES_V0500_RESULTS.json](REALISM_FIXES_V0500_RESULTS.json)。原则不变：只改机制和战术定义，不设射门、进球、长传或传球成功率配额。

## 战术体检（新增）

`work/validation/real-fixtures-20261102/cases-audit.json`：8组同水平/差0～2真实对阵，被测方取4风格×3压迫（4-4-2）及3种其他阵型（均衡/普通），对手4-4-2均衡普通，共120场。迭代时用16场快检`cases-quick.json`（4风格×普通压迫×4场，约2分钟），全量只在定版时跑。

生产版0.49.2基线发现：控球风格每场高空转移174～190次、射门5～9，是长传最多的风格；所有风格高空转移每场≥36次（现实约5～15）；被射门16～34；过人成功72～89%；角球0.4～2.5；越位接近0；传球成功率87～94%。高位压迫终场体能37～40、低位54～55，方向合理。

## 诊断与修改

| 问题 | 诊断 | 修改 |
| --- | --- | --- |
| 禁区被连续带过 | 85%的“射门时无人在门侧”来自3秒内被带过，防守者只在持球人正前方1.05～1.5米跟退，侧面追不能上抢，第二人保持2.6～3米 | `positioning.mjs`：本方30米内第一压迫人（或第一人被过后的补位者）与持球人平行或在门侧且2.2米内时直接上脚，含侧面；对抗/犯规模型决定结果 |
| 中柱漏记（线上） | Rapier从检查点恢复后，固定碰撞体的`parent()`返回刚体0而非null，中柱判定失效；生产比赛每15秒存档，恢复后中柱几乎都记为打偏 | `simulation.mjs`：按不属于球员且位于门框处判定 |
| 高球从身上弹走 | 外场球员只有脚/头触球，0.45～1.55米来球撞躯干弹开，占高空转移失败约19% | 新增胸/大腿卸球：贴身0.55米内、面向来球时走正常接球流程，来球速度含下落分量；`playableHeight`同步，高球估算不再假设首跳不可触 |
| 地面球被低估、高球被高估 | 估算对所有传球乘固定约12%执行折扣：地面球预估约85%实际约95%，高球预估高于实际 | 地面球执行估计改为传球人自身散布对比接球者滚动期间可横移距离；高球散布已在落地模型内不再重复扣；传中保留折扣；落地点取4×4等概率点 |
| 控球风格长传最多 | 风格对每脚传球按成功率加分，高空换边同样得分 | 改为风险厌恶：地面传球按（成功率−0.85）×0.06加减，高球只减不加 |
| 边路风格换边过多 | 宽点加分包括高空换边 | 宽点加分只给地面球与传中 |
| 控球侧转移加分常触发 | 判断目标附近“现在”无人 | 改为飞行+0.5秒内无对手可达 |

撤回：按“接球时空间”折算所有传球的后续价值（传球数降约20%、换边反增）。

## 结果

95场真实对阵（双方均衡，模拟/现实）：场均总进球5.68（0.49.2）→3.99（现实2.86）；强方射门26.5→16.7（14.3）；弱方射门15.1→6.5（11.3）；角球4.2→5.5（10.2）；传球出底线每场1.31→1.60；射门时无人在门侧占比36%→39%。

120场体检：被射门8～19（基线16～34），均衡对均衡两队合计射门约26（现实约25）；控球高空转移115～118（基线174～190），边路61～70且传中18～24（基线106～119），反击69～83（基线82～93），均衡65～80（基线46～57，变多）。每队进球约0.4～2.8。

## 仍未解决

1. 均衡风格高空转移增多；控球、边路风格射门偏少（4～12）；弱方射门偏少。
2. 传球成功率92～95%偏高（现实约80～85%）。
3. 射门时无人在门侧仍约39%：上抢减少了总射门，未改变漏人结构。
4. 高球接球人站位：落点准确时接球人仍可能停在约1.5米外，未触球即滚走（约11%）。
5. 过人成功约63～81%；角球约5.5（现实10.2）；越位接近0。
