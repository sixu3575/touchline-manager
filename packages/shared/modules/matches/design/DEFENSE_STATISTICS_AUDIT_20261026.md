# 防守统计与后卫评分审计 · 2026-10-26

## 结论

拦截、抢断接触、成功抢断、挡传、封堵、解围和回收均使用实际球员 ID 入账；实时/回放/赛后评分读取同一动作账本。比赛结束时个人防守数据之和与球队统计守恒，事件流、球员 performance 和评分行也一致。发现并修正了一类边界误记：挑战方碰球后若比赛因角球或任意球停下，即使定位球判给挑战方，不能仅凭重开球归属记成功抢断。只有挑战方随后实际控制球权，或获得自己的边线球/球门球，才确认成功。

## 记录路径

- 抢断尝试：进入真实近身出脚挑战时记录；跟防、压迫、封线和未形成挑战的围堵不算。
- 抢断接触：球被真实碰离对方受控状态时记录。是否成功延迟到后续结果：挑战方控制球即成功，挑战方获得边线球/球门球可作安全确认；其他死球重开不证明抢断成功。
- 拦截：防守方主动处理对方未被折射、仍有效的传球并实际控制球时记录。无主球回收只记回收，不重复记拦截；先挡偏再回收也不算拦截。
- 挡传：身体接触切断有效传递时记录，同一传递中的同一防守者去重。射门轨迹上的关键身体阻止另记封堵；扑救仅给门将实际阻止射正者。
- 解围：后场无接收者的头球/解围动作实际出球才记录，不能当作失败传球。
- 评分：新报告从同一球员统计增量生成，旧报告走兼容输入，不重写历史评分。测试覆盖逐事件和逐球员计数、球队/个人防守总量守恒、评分输入一致与死球边界。

## 为什么后卫分数仍偏低

当前 match-rating-3 防守分类是位置系数乘以递减边际贡献：成功抢断、拦截、封堵、解围、挡传和回收使用对数项；DEF 系数为1.1，而 MID 为1、FWD 为0.85。该样本里后卫防守分类约贡献+0.3分，但总评分还取决于进球/助攻、传球表现、推进、纪律、失误、在场失球及零封。防守很好的后卫若没有助攻/进球，约+0.3的防守贡献本身通常只会把6.5基准推到6.8左右；对方进球、失误或传球表现也会影响最后分数。守门员另按扑救与失球评估。

因此目前能证实的是：计数链路基本正确，归属边界已修；一场样本的防守位置分布和整体评分拉差仍不够理想。不能以单场后卫评分低就修改位置归属或给后卫虚构拦截。后续如调整评分，应先用多场固定种子按位置汇总真实成功防守、失败挑战、失球、零封与评分贡献，并单独比较“防守贡献明显但无进攻数据”的样例；此类评分校准不改变比赛决策或统计事实。

## 本次改动与验证

`statistics.mjs`将正常控球确认与停赛确认分开：重开球的`side`不再自动确认抢断成功，只有己方边线球/球门球可作为安全赢球。测试覆盖对方边线球/球门球、挑战方球门球、角球及挑战方任意球；实际己方后续控球仍可确认成功。比赛引擎测试新增球队与球员的防守字段守恒及评分/事件/performance 输入一致检查。此修复只影响新比赛的统计与评分，不回写旧报告，不改变物理、战术或赛果。
