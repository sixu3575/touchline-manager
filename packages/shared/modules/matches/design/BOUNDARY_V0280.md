# 0.28 底线控球

引擎0.28.0-boundary，参数boundary-1。2026-10-20实现候选；发布与容量验收状态见本次PR，工程通过不等于已部署。

## 根因与行为

原带球目标限制在x=1～104米，并不意味着以当前速度能在目标前收住球。motorTouch原先始终以带球档速度作为期望，controlMovement跟随球速；路线成功估计只检查对手。接球的顺势领球和早期重看也缺少底线前瞻。实际0.27归档样本有24次底线附近控制/争抢出界，其中21次在最后触球者带球事件后2秒内；一次距底线约0.98米，下一触球仍有约3.86m/s向外速度。此样本用于定位，不是全联赛分布。

新增边界风险与连续制动意图，作用于两端底线和两条边线。球路以相同草阻/空阻的groundArrivalTime估算越线时间；球员预判、灵活、平衡、当前速度和下一触球间隔决定处理余量。风险上升时更早重新观察；带球路线同时比较守卫对抗与出界风险，快带可降为近控。顺势接球在已来不及处理边界时转为卸球。真实传射和合理远射不使用该控球速度意图。

安全速度只作用于期望运动/触球方向，实际身体仍由driveMovement有限加减速与碰撞执行，足球仍须有限脚接触后施冲量。来不及刹车的球仍能出界，误差和受压失误保留；没有边界墙、坐标拉回、传中必选或每场出界配额。

## 数学细节

记有效身体制动为b=movement.braking×movement.response；常规脚触的有限调整使用其中0.6，因此边界估计采用a=0.6b，避免把完整身体刹车能力误当作每次脚触都能实现。

下一次触球时间τ随盘带为0.25～0.349秒；预判反应裕量ρ=0.08+(100−anticipation)×0.002秒。对每个边界的向外法向，剩余可控距离d扣球半径0.11米，期望法向速度取满足v(τ+ρ)+v²/(2a)≤d的非负解：

`v_safe = max(0, sqrt((a*(τ+ρ))² + 2*a*max(0,d-0.11)) - a*(τ+ρ))`

这不是物理速度硬限制：motorTouch仍从当前身体速度向期望速度作有限调整，driveMovement也受原b限制。横向分量保留可用空间，接近路线终点时另按实际剩余距离准备停车；开放场地速度不变。几何估计忽略复杂碰撞的误差，最终仍由物理接触决定。

边界风险比较实际阻力下越线时间与反应/转向所需时间，取0～1连续估计。路线成功估计减少`risk × (0.35 + 0.35*(1−dribbling/100))`；它只是候选可行性，不执行过人/出界随机抽签。风险>0.05可按预判将扫描提前最多0.2秒；风险≥0.15不采用顺势快领。四战术仍共用同一几何和运动规则。
