## 选择与执行的边界

撤回0.16新增的射门额外扣分：不再额外按封堵、压力及16米外距离扣动作评分，射门的当前位置成本恢复为0.3倍。原有射程、角度、门将位置、线路几何、能力质量及传带比较仍保留。远射能力继续扩大可考虑射程，并参与远射精度和力度。没有本场射门/传球/进球总量反馈，没有次数配额。

`decisions.mjs`选动作和一次随机目标；`execution.mjs`处理准备、转向、支撑位置与收腿；`physics.mjs`只在有限接触形状相交时给球冲量。动作准备期间不反复重抽射门选择，球继续受阻力与碰撞，对方仍能抢球。失球、球移走超过2.4米、准备超过2.4秒或死球会取消旧计划，再按新局面决策；不是因比赛统计取消。

## 工程模型与数学

以下是米/秒/弧度下的初步工程近似，**不是FIFA给出的固定人体常数**。在场景测试中先确定合理的方向和数量级，再以完整比赛统计发现模型错误；不以命中比分范围为目标反推决策偏好。

- 朝向每0.05秒连续更新。最大角速度为`(3 + 0.035×灵活 + 0.01×平衡)/(1 + 0.14×当前水平速度)`rad/s；高速时转身更慢。朝向变化取最短角差并限幅。接球者侧身兼看进攻方向与来球，近处防守者可面向球侧移；其余随移动/导航。身体平移仍使用既有加速和刹车冲量，不能瞬间停下或掉头。惯用脚判断也读取连续身体朝向。
- 脚部接触中心距身体0.45米、半径0.34米，脚方向最多偏离身体朝向90°；脚仍可在左右伸出，但不能一帧转到背后。普通触球仍需水平距离≤0.92米及真实形状相交。头/手的接触处理不套用脚部准备。
- 传球基础准备0.12秒，射门0.22秒；另加`0.002×(100−平衡) + 0.004×请求球速 + 0.015×当前人速`秒。准备和转身并行；只有准备到时且朝向差小于传球0.95rad/射门0.55rad才允许出脚。目标为球后0.5米支撑位置，步行靠近并通过原刹车减速。
- 原一脚资格（队友来球、停球≥78、决策≥72）保留；仅身体已张开（方向差<0.65rad）且来球途中实际有预观察时，可抵扣最多`0.08 + 0.002×停球`秒、且不超过已观察时长。充分准备的短传可以到球即出，不强加统一等待。背身不能靠高属性跳过转身。
- 触球后传/射恢复为`0.18 + 0.012×实际请求球速 + 0.002×(100−平衡)`秒；带球仍沿用盘带决定的0.22～0.38秒短触间隔。恢复只影响该球员再次主动触球，不冻结其他人或足球。
- 盯人平移执行使用`位置误差×2 + 已观察对手速度`，再经本人档位/加速/刹车限制。原先只有位置误差的控制器必然留下约`对手速度/2`米稳态滞后，并在2.5米内错误套用静止目标的步行/停车规则。现在移动盯人先跟速，旧观察满0.9秒后逐渐衰减、1.4秒归零；不读取新对手位置替代漏看的观察，保留甩开与追赶的能力差。
- 准备只保存可序列化动作、目标和时间。传球/射门释放前按当前球位置重新计算通向已选随机目标的速度；释放后绝不追踪目标、队友或球门。全部主动出球仍受38m/s上限、空阻与草阻约束。

现实依据：[FIFA接球与身体朝向练习](https://www.fifatrainingcentre.com/en/practice/talent-coach-programme/build-and-progress/passing-activation-playing-and-receiving-in-between-opponents.php)说明预观察、开放身体和接球方向的关系；[FIFA一脚足球分析](https://www.fifatrainingcentre.com/en/game/individual-qualities/speed-of-the-game/speed-of-the-game-5--the-minimalistic-beauty-of-one-touch-football-.php)也展示快速提前准备、协调脚步和利用来球完成一脚传递。由此推导应模拟准备条件，而非让所有球统一慢下来；具体数值仍是本项目工程假设。

## 验证和边界

针对性测试覆盖连续转向、能力/速度关系、背后有限脚触、一脚准备抵扣、远射仍被选择及真实检查点恢复。完整比赛按既有现实比较检查，分布和残余问题记录在本次校准证据中；不修改警戒线、不删除异常球员、不额外跑无关赛季。

当前不是完整骨骼/肌肉模型，没有独立踝膝关节、脚背/脚内侧动作库或专门倒钩动画。朝向和支撑为近似执行状态，不能声称达到动作捕捉精度。参数不能拿来统一压低球员速度、远射频率或人为保证低比分。
