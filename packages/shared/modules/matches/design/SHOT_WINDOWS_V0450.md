# 0.45.0 远射窗口与短期机会比较

引擎`0.45.0-shot-windows`，参数`shot-windows-1`。本次只改动作估值：远射专长、身体准备与接下来几秒的射门空间进入比较。实际出脚、球速/误差/飞行、碰撞、门将动作和整球越线保持；没有按射门次数、比分或联赛参考值反馈决策。旧回放不重算，存档结构不变；旧版本进行中任务必须结算后再部署。

## 原问题与边界

0.44以校准后的即时xG比较射门，以静态区域/空间价值比较继续传带。高远射虽能扩大射程及缩小真实落点误差，却很难改变最终选择。固定局部场景中，22米、无人施压且前方完全畅通时，即使远射95也全部选择带球；这本身可以合理，不能以此要求逢空必射。缺少的是对短暂窗口及到达后空间的统一比较。

本次保留原候选范围：最远`17 + 0.14×有效远射`米、横向离球场中线不超过20米；16～24米由终结渐转远射。**当前距离16米内保留原决策；16～24米平滑接入窗口比较，24米起完整接入。** 定位球沿原逻辑。无合法射门或在更深的组织区域时，传带估值保持原模型。

## 射门：从实际散布估计个人能力

`shot-window.mjs::shotExecution`抽出原真实射门采样器的相同参数，`shotCandidate.make()`继续使用同样的随机数顺序和公式。距离为d，动作质量为q，压力为p，横向跑动占比为l：

- 横向误差尺度`e = 0.55 + d×(0.035 + 0.26×(1-q/100)) + 0.9p + 0.35l`。
- 原瞄准点仍在中线左右1.1～2.3米，加上`1.6e×(U1+U2-1)`的三角误差。
- 高度仍为`0.15 + U×[1.5 +(100-q)/65 + max(0,d-10)×0.035 +0.4p]`。
- 球速仍取力量可提供球速与距离/压力所需球速中较小者。

估值对三个代表性瞄准偏移1.1/1.7/2.3米使用该三角分布CDF，计算球心落入门框内的估计比例，再乘高度在横梁下的比例。候选得分以`个人估计射正比例 / 同局面质量65的估计射正比例`修正原几何xG。它是候选估计，既不修改战报xG，也不直接判射正或进球。1500个种子的真实瞄准采样测试检验此近似；不能将其当作完整物理进球概率。

原摆腿耗时加上朝向超出0.55弧度后所需的真实转身时间，作为准备估计。将其与对手按原速度、加速、制动、体能/冲刺恢复和反应抵达球位的时间比较，连续降低来不及准备的射门收益。转身/摆腿仍须由执行器真实完成，预测不授予提前出脚权。

射门专长还形成有限偏好：远射相对传球/盘带越强、当前信心越高、线路越开放且身体越来得及准备，越愿意利用远射窗口；候选收益最多增减12%，不是射正/进球概率、隐藏新能力或射门配额。实际效果同时受真实能力散布、其他候选与决策扰动约束。

## 继续传带：到达后再看机会

仅当当前存在合法射门且距离超过16米时，才启用该局部比较。传球使用飞行时间及接球者停球准备（0.12～0.516秒）；带球使用共享到达模型的真实行程估计；等待使用0.4～0.994秒的观察期，视野越高越短。

防守位置预测只外推**已观察速度**，受其现有运动能力及场界限制；不读其他AI的隐藏目标、未来指令或随机结果。预测最多三秒，决策能力越高越充分读取这段运动；超过三秒的后续机会按预测信心衰减。带球者到达后的速度/朝向按路线读取，接球者保留当前运动；再用相同的射门范围、质量、门将位置、封堵和准备模型评估机会。

保留`原后续区域价值×0.25`作为不立即终结、继续组织的备选；到达后射门与继续组织取较优值，**不能相加**，否则等待会凭空得到“同一脚射门+额外球权”，又陷入不肯射门。38～26米平滑过渡到这一机会尺度；实际传球成功/带球路线风险与失去球权成本仍沿原算法，战术配合与个人传带倾向保留。先检查当前16～24米接入权重，再进行该目标区域过渡，避免突然改变禁区内终结或远处组织。

## 局部验证

固定100个种子，两方向均通过：24米中央，门将正常站位，两名防守者目前在球前8米、左右各5米，以3m/s横向收拢。持球者无贴身压力，其余能力与局面相同，仅改远射。

| 场景 | 0.44射门选择 | 0.45射门选择 |
| --- | ---: | ---: |
| 远射50、窗口收拢 | 0/100 | 43/100 |
| 远射95、窗口收拢 | 0/100 | 61/100 |
| 远射95、前方完全畅通 | 0/100 | 0/100（仍推进） |
| 远射95、三名防守者封线 | 0/100 | 35/100 |

这是局部选择频率，不能当作整场远射占比。专项还验证两方向选择对称、背身准备劣势、预测不读隐藏目标/不改真实球员、估计与真实瞄准分布相符；已有门前清晰射门、传球与突破测试保留。当前相关19项通过。

既有execution远射用例原来只有持球者、没有任何对手，强制要求26.6米处至少40/50次射门。新模型正确发现继续推进更有利，因此将场景修正为门将失位并以8m/s回撤、射门窗口即将关闭；原40/50及出脚/瞄准点/真实触球断言全部保留，34项执行测试通过。算法没有为该用例添加特例。
