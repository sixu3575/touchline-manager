# 0.6.0 校准记录 · 2026-10-17

模型：0.6.0-continuity / continuity-1。这里记录游戏模拟输出，不把结果称为真实职业联赛的统计标准。数据见calibration/v060-100.json与v060-summary.json。

## 方法

100场各5400秒完整模拟，无缩短时钟或统计倍率。世界种子42，比赛种子4200–4204；四种战术balanced/possession/counter/wide，每种5场。每个相同种子使用相同双方体能65/80/100/80/100及同一个不变对手。

五组为原始生成属性，以及仅本队passing/firstTouch/vision/decisions/teamwork/offTheBall组合设40/55/70/85；其他属性和对手保持原值。不能把85组称为“两队都85”，也不能把此组合当作全部能力等级。对手保留初始化战术。

每场分别记录同队传球链与死球间双方总传球数、稳定控制/飞行/松球/争夺/死球、失误分类、禁区进入、射门与xG。所有100场的阶段时长总和均校验为5400秒，没有计算异常。

## 结果

| 指标                       | 原始属性20场 | 全部100场压力组合 |
| -------------------------- | -----------: | ----------------: |
| 单队平均传球尝试           |        531.1 |             530.3 |
| 单队传球范围               |      393–646 |           366–814 |
| 每场双方总射门平均         |         19.1 |              26.0 |
| 每场双方总进球平均         |         3.35 |              4.88 |
| 总进球中位数               |            3 |                 4 |
| 本队≥5次成功传球链平均条数 |         22.9 |              25.0 |
| 死球分钟平均               |         22.3 |              23.6 |
| 松球分钟平均               |          4.4 |               4.6 |

40→85组合的本队平均传球尝试455.3→615.2，≥5传球链15.8→35.8，能形成更长的连续组织。总成功率并非单调：40组约79.4%，85组约75.1%。这些能力同时影响动作风险、前插和一脚处理；本次实验尚未按距离/压力分组，成功率下降的具体原因仍需验证，不能据此宣称单项技术改善或恶化。接球质量另用相同距离/压力的物理场景测试。

## 明确的局限

- 属性差距和反击组合存在大比分，极端样本13:0；85组合平均总进球7.25。不能由原始组的较好范围推断所有能力/战术都已达到真实足球分布。后续需继续做按距离、压力和动作类型的条件校准，尤其反击防守与一脚处理选择。
- 抢断尝试包含同一次贴身过程中的多次尝试，不能当成现实统计中的独立对抗次数；dribbleTouches也是实际带球触球次数，不是突破次数。
- looseCarry是失去脚下控制的阶段转换，随后对方获得控制才构成球权转移；不能将所有turnovers细项简单相加当作独立丢球数。
- xG为引擎内机会估计，未经真实数据拟合，不决定实际进球。没有为了通过范围检查而限制比分、补传球或强制传球链。
- 5个共同比赛种子支持对照，仍不足以证明所有赛季、阵型或极端参数平衡；完整赛季/API/重启/备份另由现有检查覆盖。

## 重现

仅在开发机运行（默认4个计算worker，不在1GB VM上并行跑100场）：

```sh
node tests/tools/calibrate-matches.mjs /absolute/scratch/calibration-v060.jsonl
```

该脚本未加入CI或npm脚本，没有修改原开发流程。输出存在时按key续跑，换引擎参数需使用新输出文件，不能混合不同算法结果。有限脚部10m普通能力无压迫接球测试达到≥95/100目标；跨中场及跨worker恢复比较完整事件/统计/uint16轨迹一致。VM耗时与内存单列发布记录，12×观看目标不是整轮计算耗时保证。
