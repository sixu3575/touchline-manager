## 自动检查与证据

0.16执行结果见[校准与残余偏差](CALIBRATION_V0160.md)和[汇总证据](REALISM_EVIDENCE_V0160.json)。新增20Hz原生五区/活动测量，5Hz保留作独立距离对账；团队阶段时长有档案，但含短时松球，仍不是每个个人稳定控制片段。观察延迟次数/压迫任务时间只作诊断，不冒充实际盯人失误/成功压迫。既有review/block阈值保持。

- `tests/tools/match-realism.mjs`只读已有详细报告/轨迹，不导入引擎、不改变随机数或旧报告。`tests/match/engine.test.mjs`复用既有90分钟确定性样本，不额外打一场。
- `scripts/validate.mjs`为本次运行分配独立证据文件，`work/validation/result.json.realism`嵌入比较结果，CI上传`work/validation/realism/*.json`；不会将上一次报告当本次证据。
- `pass`为未越线；`review`有需解释的警报；`blocked`阻断比赛专项。检查在原断言之后失败，先保存报告。没有运行真实层级时为`not-run`，不能声称现实性通过。
- **已知0.15.1未通过新门槛**，本次诊断/工具PR的普通检查可以通过；这不批准新的比赛算法发布。后续算法PR触发真实专项时必须解决实际阻断，不能加临时白名单。
- 普通UI/文档/修补不因此跑比赛/赛季。本次额外8场是用户明确要求的诊断。以后调整引擎平衡时需提供至少同一基准8场的分布比较；无需扩大成完整赛季。可复用已存在且输入/版本完全相同的报告，不为同一数字重复计算。

```sh

npm run check
# 引擎平衡诊断：仅在需要诊断/改算法时显式运行；不要在1GB生产VM运行
node tests/tools/calibrate-realism.mjs work/realism/本次唯一目录
```

八场矩阵：固定世界42，比赛999/1001，主队balanced/possession/counter/wide，客队原战术；使用普通初始球队，每次从相同输入重新开始，最多4 worker。不是八种等强战术对抗，也不是联赛样本。另加的超级球员/低体能/力量差专项必须独立标注，不能混入普通球队均值。工具记录提交、dirty、版本、种子、战术、每场警报及分布。生产只读分析输出必须留在Git外。

## 参考与口径

参考数值/URL随工具版本保存，取自UEFA EURO2024身体报告、FIFA英美2022单场报告、UEFA2024总进球。官方数据是精英足球锚点，**不等于虚构低级联赛目标**。

UEFA身体数据不含门将、取90分钟部分；按位置首发>70分钟，距离/速度区间见报告9–10页。FIFA英美报告包括补时；它的550/427传球、8/10射门仅是单场例子。UEFA117球/51场含加时，不应冒充每90分钟进球均值。位置对照：中锋F、边锋/边前卫WM、边后卫/翼卫WD、中卫CD、中前卫/后腰CM，门将无套用外场参考。

比较输出同时含：

- 球队：比分、射门/射正/xG、传球/成功率、控球、拦截/抢断/成功数、犯规/红黄牌/角球/越位/扑救、外场跑动、体能触底人数；链长度、死球/有效时间、争抢/松散球、禁区进入、模型球权事件。
- 球员：位置/分钟、距离/每90分距离、峰速、五速度区轨迹估计、低速占比/高速/冲刺距离及现实位置均值/标准差；传球/成功、触球、带球触数/距离、直塞/长传/一脚出球、射门/进球/助攻/关键传球、抢断/成功/拦截、扑救、纪律、失误。新版内部对照另记录终场爆发储备与肾上腺素短冲次数，八场汇总保存两项分布及实际触发场数，用来检视恢复/关键爆发机制，不作为玩家统计或官方生理量。旧版关键传球来源不足不能作精确事实。
- 五区为0–7、>7–15、>15–20、>20–25、>25 km/h。回放只有5Hz、厘米量化，速度由平面差分估计；剔除切帧两侧/明显跳变/罚下后/加时点球段，报告覆盖率。不是光学25Hz原始测量，也不是官方冲刺次数。
- 精确稳定球权时长、摆脱/对抗后保有率、盯防失误和压迫成功尚缺档案数据，明确列缺失。最后触球者不当稳定控制者；丢失控制计数不当对手夺权。评分没有统一的官方现实量表，不能伪造精确对标。

## 工程警戒线（初版，非官方百分位）

以下只筛查明显异常；不同等级、战术、红牌及能力差可以产生例外，`review`须在PR解释上下文，`block`须先改进算法或提出有来源的阈值修订。它们约束验证判断，不限制生产的真实比分、球员速度或统计。

| 指标                           | review范围        | block界限                                       |
| ------------------------------ | ----------------- | ----------------------------------------------- |
| 每队传球/成功率                | 200–850 / 60%–96% | 缺少数值阻断                                    |
| 每队射门/进球/xG               | 2–30 / 0–8 / 0–6  | 射门>45，进球>10                                |
| 全场射门/进球                  | 10–40 / 0–10      | 射门>65，进球>14                                |
| 出场≥60分钟外场每90分距离      | 6–14.5 km         | <4或>17 km                                      |
| 单人峰速                       | —                 | >40 km/h或缺失                                  |
| 出场≥60分钟射门/抢断尝试每90分 | ≤12 / ≤15         | >20 / >25                                       |
| 外场低速距离占比               | 25%–65%           | 暂仅review，待20Hz积分补齐                      |
| 高速/冲刺距离每90分            | ≤2 km / ≤1.2 km   | >3 km / >1.8 km                                 |
| 回放距离相对报告偏差           | -8%至+5%          | 暂仅review；5Hz弦长可少计，子步覆盖会使报告少计 |
| 外场轨迹覆盖率                 | ≥95%              | <95%                                            |
| 一队体能到20人数               | ≤4                | 暂仅review                                      |
| 普通球队8场均值                | 完整输出分布      | 平均总进球>7或总射门>45                         |

没有公开且定义兼容的低级联赛数据时，不给拦截、抢断、控球片段等杜撰“现实区间”。先报告模型原值与缺口，后续以同定义实际样本丰富参考。单次基准通过也不意味着整套参数已校准；平衡PR须结合八场分布、专项、异常片段及与前版的同种子对照。
