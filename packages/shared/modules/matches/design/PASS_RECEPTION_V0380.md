# 0.38.0 传球落点争夺与出脚前重评

上一版传球候选把“球能否穿过线路”与“接球队员能否处理来球”分开估计；一般地面传球没有模拟防守者是否先到接球点。出脚准备期间虽然会在特定风险下重新选动作，但风险只在出球时重算，且对旧成功估计额外容忍20个百分点。结果是传球估值容易偏乐观，容易把球送到防守者脚下；高传球值缩小的落点误差也无法弥补落点本身被盯住。

0.38.0给每个普通传球和传中候选增加接球点竞速估值。它比较队友与对手到达落点所需时间，使用当前位置、速度方向、加速/制动、疲劳状态和防守预判；传中还保留接应类型与近身防守者的空中/脚下对抗评估。沿途拦截与落点争夺取同一防守球员的较高威胁，以免把一个人重复算成两次独立丢球风险。接球队员的第一触球能力仍单独影响处理难度。

质量评分仍由传球80%/平衡20%组成。高传球值收窄实际落点散布、提高候选的准确度估计；视野扩大可见队友距离并影响直塞条件，决策降低选择扰动并加快对变化的响应。球速依照既有地面阻力解算，不会因传球数值直接加速，也不直接奖励进球、助攻或评分。

球员完成转身和准备、即将实际触球前，系统会用此刻的球路、接球者和防守站位重新估计成功率。估值相对初选下降超过由决策值决定的4～12个百分点时，重新比较当前可行选择；只允许一次重选，重选后留有0.8比赛秒复核冷却，避免持球者不断取消出脚。重选仅调整行动选择，球仍须由真实有限脚触产生冲量，之后按物理接触和球路判定结果。

本模型是工程近似，不是职业比赛中的实际概率回归；四战术×两种子只用于观察分布变化，不以目标成功率或传球次数强行校准。相同输入的八场前后对照中，每队尝试传球均值543.3→502.3（−7.6%），加权成功率85.7%→88.7%（+2.8个百分点），拦截53.8→32.7（−39.2%），丢失球权88.3→68.2（−22.8%）；传球尝试的队级样本方差9135→10870，成功率方差0.000551→0.000451，保留了不同战术/种子造成的差异。每场射门均值29.0→27.9、进球3.25→3.13；本改动不是射门或比分校准。队级传球尝试样本范围410～763，仍处于验证契约200～850的宽泛筛查范围。

现实性检查为2场`pass`、6场`review`、0场`blocked`，无分布告警；14条`review`警报均来自已有的球员低速跑动占比提醒，与传球机制无关。专项执行测试34项通过；固定矩阵八场全部完成。矩阵是小样本模型对照，不证明现实概率已校准，也不用于给球员设成功率目标。新比赛记录引擎`0.38.0-pass-reception-contest` / 参数`passing-contest-1`；旧报告和回放保留原样，旧检查点不跨引擎续算。
