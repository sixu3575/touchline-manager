# 0.42.0 防守协同与离位风险

## 目标

现有防守目标会随球移动，但常规球侧响应较弱；有球侧上抢通常只派一人，高压最多两人。近身压力只取最近一名防守者，因此第二人即使靠到身边，也很少改变持球人的传带难度。大多数队友继续守分配的线位，决策、预判和团队配合很难转化成“读出空间并及时补上”的比赛表现。

本次让防守职责按实际空间和球员阅读能力调整。球员可离开阵型锚点跟球、跟危险跑位或参与围抢；需要通过目标点和物理移动到位，不会瞬移，也不直接判定抢断成功。

## 算法行为

- 球侧阵块：均衡防守的横向目标系数从0.18提高至0.30；控球战术对手仍用0.65，反击保持0.12。个体的决策、预判、站位和团队配合使其更快、更积极地移动到球侧，覆盖范围有差异，不把整队锁在初始锚点。
- 协同围抢：低压最多一人；正常压迫在距离和协同属性合适时可加入第二人；高压可加入第二、第三人。第一人接近持球者，第二人趋向最近的接应线路，第三人从另一侧靠拢。围抢半径和人数仍受球员当前位置、压迫指令与防守纵深制约。
- 阅读属性：决策、预判、站位和团队配合共同构成协同阅读。候选第二/第三名要达到相应距离和团队平均阅读门槛；高压三人围抢还要求第三人足够接近球并满足纵深条件。盯人、预判、决策则提高防守者分配及跟踪进入中场空隙的倾向。低阅读能力更常守住原阵块或错过交接时机。
- 围抢收益：动作质量读取最近防守者的压力，并让4米内的第二名继续压缩持球处理空间；实际靠近球的队友仍按现有最多两名协防规则参与抢断争夺。只有真实位置产生作用，不为“被分配围抢”虚构成功率。
- 围抢风险：被选作压迫者的球员退出专职盯人与保护人员池；因此可减少被直接指派的防守者，未覆盖跑位者可能获得空间。若压迫者未及时到位，或第二人封错线路，进攻方仍可通过传跑利用空隙。

这些行为由`defending.mjs`选择上抢/盯人/保护职责，`positioning.mjs`形成各自的场上目标，`offball.mjs`读取跟人和交接，`locomotion.mjs`执行跑动，`skills.mjs`根据实际近身位置衡量压力；物理碰撞和规则判定仍负责最终对抗结果。

## 验证方式与结果

定向场景覆盖：阵块对球侧反应随阅读能力变化；高阅读防守者更积极跟入中场空隙；低阅读高压队较难协调出第二/第三压迫者；高压人数增加时进攻跑位的专职盯防会减少；第二名防守者真实靠近后，传球质量压力和现有协防抢断估值提高。

真实比赛验证按既有流程运行完整90分钟固定矩阵：4-3-3下均衡、控球、反击、边路四种风格各用种子999和1001；另外反击风格对高压各一场。使用原始球员与真实模拟，不推进存档或赛季。后台比较保留全场统计、球队/球员跑动和防守计时；本设计不把新增诊断数据投放给玩家。

**结果：** 15项战术定向测试和8项比赛现实分析测试通过。10场矩阵完成，6 pass / 4 review / 0 blocked，无分布告警。4场review来自球员低速跑动占比（23条球员级review）；另有一场单队传球1047次触发传球量review。整场均值为每场双方合计2.0球、19.38次射门；每队562次传球，范围344～1047，说明高传球尾部仍需另行审查。

后台指标确认战术仍然不同：控球风格58%控球、每队944次传球、16.44脚平均传球链；均衡为49.5%、525次和9.86脚；边路363.5次、反击469次。相同种子反击对照把对手压迫从正常改为高压后，对手两场合计平均压迫职责时长从2049增加到3315.5球员秒（+62%），盯人职责时长从7267降到6363球员秒（−12%）。这验证了“更密集地施压，同时减少专职盯防”这一收益/代价方向。两组抢断尝试分别为17.5与20次，单场差异有波动；压迫不会保证抢断、比分或胜负。整体现实性仍为review，以上不表示全场节奏和分布已经完全达标。
