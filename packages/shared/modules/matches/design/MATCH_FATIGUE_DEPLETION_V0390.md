# 全场体能消耗与属性差异校准 v0.39.0

## 目标与改动

上一版四战术×两种子样本的全场球员终场体能均值约66；七日恢复时高低力量/耐力球员拉开的差异也有限。本次将普通全场球员的终场均值调整到40–50附近，同时让力量、耐力同时影响赛中耗能与赛后恢复。体能仍从实际移动、压迫和球员参数逐步计算，没有按角色或终场时钟指定剩余体能。

- 赛内耗能基准系数：`0.64 → 1.08`。
- 持续容量：`C=70+0.45N+0.20S`。耐力`N`和力量`S`均读取球员真实1–100整数属性。
- 运动经济性：`Q=1.30−0.0055N`，使耐力高的球员完成相同运动时耗能更少；每步实际能耗再由`100/C`缩放。
- 七日轮间恢复率：`k=0.02+0.00075N+0.0015S`，恢复值仍由原指数恢复过程计算。力量对恢复的影响加大，耐力也继续生效。
- 原有疲劳对身体/技术有效能力、持续跑动输出、冲刺储备、压迫强度、训练负荷及同日杯赛规则不变。表中精度仅供模型说明，玩家界面仍显示整数体能。

从相同赛末体能45出发，七日恢复样例为：

| 耐力/力量 | 恢复率 k | 七日后体能 |
|---|---:|---:|
| 20/20 | 0.065 | 65.1 |
| 50/50 | 0.1325 | 78.2 |
| 90/90 | 0.2225 | 88.4 |

这组比较固定了赛末体能以单独显示属性的效果。实战中高负荷也可能让高属性球员的赛末体能不同；训练安排随后照常扣除4–8点或在体能恢复区补14点。

## 同输入比赛对照

使用仓库既有现实性比较器，在相同初始球队、比赛种子和四种战术下，各运行种子999与1001，共八场。基线是引擎`0.38.0-pass-reception-contest`，候选是`0.39.0-fatigue-depletion`。赛末样本统计仅纳入完整出场90分钟的外场球员：每组160人，8场×每场双方各10名外场球员。数据取比赛报告记录的最终体能。对照没有推进真实存档、联赛或赛季。

| 指标 | 0.38基线 | 0.39候选 |
|---|---:|---:|
| 完整出场外场球员终场体能均值 | 66.0 | 42.6 |
| 中位数 | 65.35 | 42.0 |
| p10–p90 | 59.4–72.3 | 32.9–52.9 |
| 最低–最高 | 53.7–75.5 | 21.7–60.4 |
| 个体落在40–50（含端点） | 0% | 38.75% |
| 每场总进球均值 | 3.125 | 3.25 |
| 每场总射门均值 | 27.875 | 25.0 |
| 每队尝试传球均值 | 502.3 | 496.6 |
| 外场球员每90分钟距离均值 | 8,558米 | 8,230米 |

终场均值和中位数进入目标区间；球员之间保留了由跑动量、位置、比赛行动和属性产生的自然差异。因此p10和p90会在40–50之外，个别人更低或更高。耐力+力量综合属性最低四分位平均为耐力57.4/力量38.0，七日后均值71.3；最高四分位为63.4/67.6，七日后均值82.9。这个组间比较同时包含赛末各人的运动负荷，不等同于固定赛末体能的属性消融；上表45体能对照用于隔离恢复率本身。

整体比赛统计没有随耗能倍率同幅下降：进球基本持平，射门减少约10%，队级传球减少约1%，外场距离减少约4%。体能机制可影响已存在的能力/运动输出，不能单凭八场小样本断言整体比赛节奏已拟真。

## 验证状态与限制

八场候选完整结束，结果状态为`review`，没有分布阻断。review包含原有低速距离占比提醒，以及一名球员的射门数提醒；它们不表示体能终场目标失败，也仍需在今后比赛统计中观察。该对照是工程参数校准，不是人体生理医学测量或职业联赛体能数据库；样本战术、阵容与种子数量有限。

新增/更新覆盖：耐力与力量分别影响容量、消耗、短时运动、七日恢复；固定赛末体能下的高低属性恢复差；局部比赛耗能更新；周间冻结状态的渐进恢复范围。验证按现行规则运行比赛专项和完整`npm run check`，不跑赛季。没有存档结构迁移；已保存球员体能不批量调整，既有历史比赛及回放也不重算。部署前仍需经过PR CI与发布核验。
