## 战术应怎样产生实际作用

战术通过职责、空间、跑动时限和候选选择影响比赛，不能直接修改最终比分或给弱队保平概率。阵型与风格、压迫分别选择：5-4-1可用于其他风格，选择低压才意味着更深的阵块。

| 意图          | 实际执行与收益                                                                                                       | 代价和克制                                                                                       |
| ------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 控球组织      | 中场/边卫提供球后接应，受压时安全回收；对手球侧人数多而远侧空才转移；线间拉开才送身后球                              | 倒脚本身不产生射门机会；人球真实运动才消耗体能，过多安全接应会失去纵向出口                       |
| 快速反击      | 真实夺回后阅读尚未落位的防线；前锋和边路从自己的当前位置向前启动，比较地面直塞和过顶球；低压时留一个前方出口         | 跑者越过越位线会被约束；传球不保证接成；等待过久、对方落位后窗口结束；留前锋会减少回防人数       |
| 边路进攻      | 宽点、内切、条件式套边、近远点包抄和倒三角；终结/头球与个人突破能力决定可用路线价值                                  | 套边必须有保护和通道；远侧包抄腾空原防区；低位防守保护中央时会让出更多边路空间                   |
| 5-4-1低位防守 | 三中卫、两边卫、四中场形成两道保护；横向保持区域责任，交接远离球的盯人；危险区域允许第二人近身协防；一名前锋留作出口 | 单前锋容易孤立；中场过深可能无法出球；换边与持续边路进攻可能牵动边卫；实力差不被抹平，不保证守平 |

## 国际比赛数据：口径与结果

共211场：2018世界杯64场、2022世界杯64场、2024欧洲杯51场、2024美洲杯32场。只取上下半场及其补时，不计加时和点球大战；比分从进球/乌龙事件重建。统计包括射门/射正/xG、传球/完成率、抢断、拦截、盘带、禁区外射门、定位球、犯规和牌，逐赛事/分组输出均值、样本方差、分位数与样本数。缺项不补0。

## 已确认问题与候选修复

1. 防线原有“能力落后时不得伸脚”的额外资格限制，与实际对抗概率重复削弱弱者。现在保护来自球是否在身体后面、脚下是否真正可触及；球在身体下方仍受保护。技能差只进入原对抗概率，不授予高手触球免疫。
2. 低压原本总是仅一人靠近，其他人容易追随远侧无球威胁。现在门前28米内、第二人距持球者6米内且协同均值至少40时可第二人上抢；三中卫对远侧/远球跑位保留区域责任，中央门前威胁仍完整跟踪。围抢者从盯人/保护池移除，收益有实际失位代价。
3. 跟跑速度超过可持续跑速时，原先等目标误差超过4米才冲刺，主动送出空隙。现在误差超过0.8米就可匹配观察到的快跑；仍受本人体能、爆发恢复和真实极速限制。危险补位及失去门侧的回追也可紧急提速。
4. 反击只数球门侧人数，无法区分八人紧凑阵块与八人分散站位。新增读取可见中场/后卫线间距；大于14米时窗口最多14秒，否则沿原8秒与不足7人在球门侧条件。队内传球不刷新夺回时间。前方跑者从本人的当前位置继续启动，避免深回收把前锋指向身后的错误目标。
5. 传球落点“防守者先于球到达”原来近似必丢，忽略接应者已经先占位置。现在将双方到达差、停球/平衡/灵活纳入接球争夺；线路中段拦截仍按真正到达时机判断。失球代价按传球目标和潜在线路拦截点估计，长球失在对方半场不再一律按本方禁区丢球处罚。
6. 底线附近的区域价值和预期门将位置存在几何偏差：正确守住近柱的门将可能被误判成让出空门。预期位置与实际站位共用门口横向范围；底线远离门框时降低区域价值，保留倒三角/回收价值。保留原射门出脚、误差采样、xG表达式与合理远射候选，不靠禁射制造平衡。
7. 门将不再追着受保护的底线持球者离开近柱；斜向高速球也进入原扑救链。准备时双手保持约0.9米基础高度；真实手部垂直伸展读取身高与制空，修复“只放宽资格、实际手永远够不到高球”的不一致。手部球体仍0.35米、手臂速度仍有限，不远程判扑出。
8. 长传接应估计假定能冲刺，但执行曾按“球距本人18米内”才提速，长传落点来不及赶到。现在指定接应者按剩余到球时间与所需跑速选择冲刺；反击跑者在出球者视野可达范围内也可提前启动。高空球接应点须同时满足高度可达，不能只看平面路过就停在球下。均保留体力/爆发/惯性限制，不授予必接成功。

## 数学与工程参数

- 真实对抗仍使用原 sigmoid：`(防守质量−盘带质量)/28 + 距离先手×1.2 + 协防×0.35`，概率保护区间2%–98%，协防最多2。带球路线估计采用同一对抗模型；禁区内门将估值用单刀50%/接球30%/反射20%，实际仍须手形接触。
- 低压后卫线纵深：`2 + 球纵深×(0.42+(协同−50)×0.0005)`，位置保护范围4–26米；中场间隔约8米，后腰稍后、中前卫稍前。正常/高压基线分别0.50/0.57及38/46米位置保护。此为跑位意图边界，允许上抢、跟踪和危险补位离位，非实体屏障。
- 低压中卫宽度系数0.55，边卫随球深入由0.72收至0.55；低压/反击其他位置0.72，普通0.78。球侧响应基线低压/反击0.24、普通0.30、对控球0.65，再随协同属性修正。
- 接应争夺质量：停球65%/平衡20%/灵活15%。对手到达产生暴露度，再按双方质量及到达时间先后进入同一sigmoid；多名对手按条件生存率累计。不是传球成功抽签。
- 门将双手最高目标：`身高×1.28 + (0.2+制空×0.004)×已反应倾侧程度`；身体、手部传感体积、反应和移动速度仍须共同满足真实接触。不会因为提高资格高度就自动扑到。
- 反击前插目标取“本人位置+10+准备度×8”与“球位置+17+准备度×13”较大者；限制在合法越位线前，低准备度额外留至多3米缓冲。准备度=无球30%/决策18%/加速22%/冲刺30%，均读取比赛有效能力。
- 接应者尚有到球时间且目标差大于2米，目标差/剩余时间高于可持续跑速的80%时，产生提前冲刺意图；不再要求足球先进入18米。反击无球启动距离取出球者`18+视野×0.45`米可见范围；其他职责沿原距离规则。高空接应扫描排除预计高度超过身高加0.35米的点。

## 验证和限制

新工具 `node tests/tools/calibrate-strength.mjs OUTPUT_DIR [CASE_CONFIG.json]` 只计算隔离的完整90分钟，不推进生产存档。默认36场：60对60/70/85 × 弱方4-4-2低压反击、5-4-1低压反击、4-4-2正常均衡 × 两组生成球员 × 两种子，并交替主客。强方固定4-3-3正常均衡；记录实际首发均值、W/D/L、射门/射正/xG/传球/控球/犯规的均值、方差与逐场数据。使用全部属性整数平移且保持生成专长，因此与同均值但不同属性形状的队伍不等价。强弱分组不能由这36场推成稳定胜率。

首轮36场候选仍阻断：60对85的12场全部弱方失利，5-4-1四场0:11、0:7、0:9、0:4，不能把个别种子0:2的改善当作成功。随后修复反击回跑、盯人跟速、门将手部/斜球后，最终矩阵另存；最终结果见下方追记。

既有专项断言迁移：出脚窗口测试仍保护脚下近控，但暴露在前方的球不因数值差免疫；接球落点测试仍要求有人覆盖明显高于空位风险，但双方已在场的争夺不再期望“必丢>90%”。没有删除旧断言来绕过问题。另有5-4-1大组/镜像、临场命令与检查点恢复、合法反击前插、跟跑/零体能、门将近柱/高球、传球中段丢失代价的定向验证。

四战术×两种子及高压反击10场现实矩阵仍须单独执行。工程通过不能替代强弱对抗现实性通过；任何block均禁止部署本算法。临场阵型服务端允许值变化按当前分类器触发生命周期验证，保留既有流程，不通过改分类器省略检查。

仍有四项关键缺口：

- 60对85时弱方射门/有效威胁接近零，5-4-1即使少丢球也不能据此认定“可行防反”。
- 强方个人射门/弱方个别人的挑战次数集中；部分场次比分仍达0:12或0:16，已有工程block不豁免。
- 源码复核发现射门封堵估计仍用球门中央的地面线路，而实际射门瞄准两侧且有高度轨迹。这是尚未修正的估计/执行口径差，应以同一射门几何和真实球路复核，而非统一抬射门分。
- 全属性平移同时放大技术、速度、耐力和门将能力，不能将25点总能力差认作世界杯两档。后续须分开“技术差但运动能力接近”和“身体/技术全方位压倒”，保留当前极端压力样本，不以换样本隐藏失败。
