# 真实对阵修复：禁区防守、射门、门将、疲劳与统计口径（0.48.0-defence-fatigue）

承接[真实对阵复盘](REAL_FIXTURE_AUDIT_20261102.md)，原始汇总见[REALISM_FIXES_V0480_RESULTS.json](REALISM_FIXES_V0480_RESULTS.json)。原则：只改机制本身，让结果自然变化；不设射门、进球、比分、黄牌或控球配额，不针对某个统计数字加上限。允许方差和爆冷，以现实分布为准。

## 验证方法

- 95场2023-24真实对阵（FC24属性、按总评差分层），双方4-3-3均衡正常压迫，每场固定种子；与同档3,434场现实比赛比较。脚本在被忽略的`work/validation/real-fixtures-20261102/`，诊断脚本在`work/validation/blowout-diag/`。
- 每场保留完整事件与5Hz轨迹，用于射门位置、射门瞬间防守站位、门将扑救率、各15分钟体能与表现分析。
- 同一种子下代码的微小改动会让单场结果完全不同（混沌放大），所以只看95场合计和分档分布，不以单场或8场子集判断。

## 根因（诊断结果）

1. **统计错误**：门将扑出后后卫再碰球，射门被改记为"封堵"并扣掉射正。此前"大量射门被封堵"的结论主要来自这个错误。
2. **悬殊比分不是射门太准，而是机会太好**：大比分比赛中强方射门平均距离约9米（现实约17米），48%的射门射手与球门之间没有任何外场防守者，26%来自小禁区。140/193次射门前6秒内有变向突破。
3. **禁区防守**：
   - 防守者只站位跟防，不会主动抢趟出的球，球碰到脚上才算一次抢断。
   - 选谁主防按"跑到球现在的位置要多久"排序，于是身后追不上的人被选为主防。
   - 正常压迫下，第二人包夹要求协同意识≥66（低位防守只要40），60档球队在自家禁区几乎永远只有一人应对持球者。
4. **带球太快**：高盘带球员全速带球可达本人冲刺的约94%，快过弱队后卫空手冲刺。现实中带球冲刺比空手慢约10～20%。
5. **门将能力过陡**：扑救横移加速度是跑动加速×响应×扑救反应三项连乘，55与80门将相差约57%。禁区中路扑救率从52%（<65门将）到77%（75+门将），现实中好坏门将约差8～10个百分点。
6. **疲劳重复计算**：冲刺速度属性已按疲劳折损，再乘一次努力系数，终场峰值速度下降约16%、高速跑动下降约60%（现实约3～5%与15～25%）。判断类属性不受疲劳影响，末段传球成功率反而上升，进球逐时段减少（现实末段最多）。
7. **射门**：高度散布几乎不随距离变化，20米远射打飞概率仅约9%；射门误差不看来球速度，一脚打迎面快球和停稳再射一样准。上一轮加入的对数几率误读幅度约为原统一噪声的2～3倍，门前11米单刀也可能被误判而选择持球。

## 修改

| 位置 | 机制 |
| --- | --- |
| `attribution.mjs` | 扑救或中柱后，外场球员碰到反弹球不改写原射门结果，除非球仍飞向球门（门线解围）；统计版本`opta-conventional-3` |
| `statistics.mjs` | 过人尝试在分出结果时记一次：越过对手（成功）或在对抗中丢球（失败）；接触后选择传/射不计；动作统计版本`actions-2` |
| `defending.mjs` | 持球时压迫成本改为能否截住持球人当前运动路线（`arrival.mjs carrierIntercept`）；门前28米内，所有压迫档统一允许在持球者6米内、与球平行或在球门一侧、协同≥40的第二人包夹 |
| `positioning.mjs` | 主防在持球人把球趟出、本人能先于持球人到球时上脚争抢；胜负仍由原对抗模型决定，失败仍有恢复时间 |
| `locomotion.mjs` | 冲刺速度属性按原值读取，疲劳只经一次努力系数`min(0.85+0.15√体能, 0.35+5×体能)`；带球冲刺为极速的`0.80+0.0008×盘带` |
| `players/match-state.mjs` | 决策/预判/站位/专注/镇定随体能温和下降（`0.9+0.1×体能`） |
| `goalkeeping.mjs` | 扑救横移是独立爆发动作，加速度`12.6×(0.85+0.003×单刀)×(0.85+0.003×灵活)`（65/65门将与原值相同），不再与跑动加速/响应连乘；射手读门将覆盖的估计同步 |
| `shot-window.mjs`、`decisions.mjs` | 射手按可见门将覆盖与本人散布选横向落点；高度以约1米为中心上下对称，散布随距离与横向同步放大；来球相对脚的速度与离地高度增加误差，技术可化解一部分；开放射门误读改为对数几率，幅度`±(0.05+0.35×(1−决策/100))`，与原统一噪声对正常机会量级相当 |
| `rules.mjs`、`simulation.mjs` | 第12章"破坏有希望的进攻"黄牌：推进超过50米、向前速度>3m/s、门侧≤3名防守者 |

撤回的尝试：按控球片段固定的决策倾向（传球次数从约530跌到118）、所有风格中锋包抄（无可测效果）。

## 仍未解决（下一步）

1. **持球太安全，导致弱队打不出进攻**：传球成功率约91%（现实约82%），弱队反而控球约53%、传球约730脚，但每场只有约5.8脚射门。20～30米远射被回传比下去，禁区外射门仅占强方6%、弱方19%（现实约35%）。需要从传球执行误差和抢截机会入手，而不是给远射加偏好。
2. **机会结构偏向带到门前**：强方31%射门在小禁区（现实约7%）。禁区协防已改善但仍不足。
3. **悬殊对阵尾部仍偏重**：10～14分档强方场均3.8球（现实约2.7），方差仍高于现实。
4. **末段进球偏少**：疲劳的身体衰退已符合现实，但进球仍逐时段下降，末段失误不够多。
5. **过人成功率约69%**（现实约45～55%），属于玩法本身而非统计口径。
6. **角球约3.4（现实10.2）、犯规17（现实22.5）**，与传中、出界和对抗频率相关。
