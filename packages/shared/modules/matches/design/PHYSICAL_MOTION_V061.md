# 0.6.1 跑动与球体减速检查

用户要求检查属性到实际跑速、防止异常高速/缓慢，使落地减速合理。物理改动只涉及比赛运动与展示，球员档案/持久表不变。用户另于2026-10-17明确批准两项流程调整：测试文件最多4个并行，CI仅PR/main push以去重；其余流程保护不变。

## 球员

身体有效属性 A：原属性乘 `0.7+.3*sqrt(E/100)`，限制1–100；E为当场体能，比赛中最低20。姓名、国籍、名气不加速度，年龄不另叠隐藏倍数，现有自然衰退尚未实现。

| 动作 | 目标速度（m/s） |
| --- | --- |
| 步行/近距离调整 | 1.5 |
| 慢跑 | 2.7+.014A冲刺 |
| 正常跑/补位 | 4.3+.022A冲刺 |
| 冲刺 | 5.7+.036A冲刺 |
| 带球 | 冲刺速度×(.60+.002A盘带) |

冲刺属性20/50/80/100、满体能时分别6.42/7.50/8.58/9.30m/s（23.1/27.0/30.9/33.5km/h）。正常停步、护球和球的慢滚允许低速，不设置虚假的最低速度。

加速`a=2.4+.035A爆发`，制动`b=4+.04A平衡`，响应`r=.55+.0045A灵活`。期望速度先限到动作档位；`Δv=期望速度−当前速度`，每步实际改变量的模≤`a*r*dt`，减速/转向用`b*r*dt`，以`J=mΔv`施加有限冲量。躲避队友不能叠加超速，转身不能瞬间反向。门将保留已批准的短时扑救响应，仍受速度限制。

身体碰撞仍影响位置和动量；每子步后超过个人有效冲刺速度+0.6m/s时移除超出部分，避免重叠胶囊把人弹飞。这是数值保护，不是真实骨骼/撞击模型。最大允许瞬时9.9m/s（35.6km/h），正常主动冲刺仍≤9.3m/s。FIFA记录Hakimi单场峰值35.3km/h仅作量级核对。

## 足球、空气和草地

质量0.43kg、半径0.11m（周长约69.1cm），在IFAB的410–450g/68–70cm范围内。重力9.81m/s²；Rapier仍计算地面法向碰撞、弹跳、球员/门框碰撞，触球仍须有限形状真正重叠。

旧问题：固定0.21.0 JS绑定未开放解除高速自转限制。20Hz时8m/s纯滚动需要约72.7rad/s，却被限制到约15.7rad/s，地面持续按打滑处理，叠加过强摩擦。旧实测8m/s在1秒后4.76m/s、11.60m后停止；原线性空阻又过弱，30m/s空中球1秒后水平仍29.64m/s。

修复：草地切向摩擦设0/Min，法向碰撞/反弹继续由Rapier求解；明确的阻力冲量替代与引擎自转上限冲突的切向摩擦。其他碰撞材质保持原参数。原生自转仍为简化状态，不能当作精确旋转球模型。

- 二次空气阻力`F=−.5ρCdπR²|v|v`，ρ=1.225kg/m³、Cd=.25，`k=.5ρCdπR²/m≈.01354m⁻¹`。Cd取NASA示例的工程近似，不是不同球皮/雷诺数的拟合。
- 子步先以阻力项的精确更新`v'=v/(1+k|v|dt)`施加冲量，再由Rapier积分重力/碰撞；这是分裂积分，不是整个方程的解析解。
- 贴地（球心y≤R+.002m）且垂直速度绝对值<.75m/s时，水平速度每子步减最多`.65dt`，到0即停且不反向；地面同时耗散旋转能量，避免静止球长期空转。快速下落/弹起不提前施加草阻。
- 稳定地滚球近似`dv/dt=−(.65+k v²)`；高速阻力更大，低速逐渐停止，没有最低球速。
- 主动触球三维初速≤38m/s（136.8km/h），地面传球规划≤30m/s；这是异常输入保护，不是所有出球的目标。FIFA的2022世界杯最强进球射门123.34km/h仅供量级核对，不能当作所有射门绝对上限。

## 决策与展示

地面传球到达要求`v_a=clip(4.5+.17L+.015Q,5,14)`，初速`v_0²=(v_a²+a/k)exp(2kL)−a/k`并限制30；限速后重算实际到达速度。飞行时间`t=(atan(v_0√(k/a))−atan(v_a√(k/a)))/√(ak)`。接球预测使用同一地面阻力，空中预测只使用空阻近似。

高球/射门按平均阻力率λ近似反解：`v_x=Δx*λ/(1−exp(−λt))`，`v_y=Δy*λ/(1−exp(−λt))+g*(t/(1−exp(−λt))−1/λ)`，λ由平均三维速度估计。实际仍由瞬时二次阻力积分，不能强制到点或命中。

回放球速包含垂直位移，球员速度仍为水平位移；按物理采样间隔计算，不乘播放倍率，cut重开帧不算瞬移速度。5Hz显示为区间平均，不等于子步瞬时峰值。

## 验证与边界

`tests/physical-motion.test.mjs`覆盖实际刚体属性/体能差异、有限刹车转身、冲击限速、3/8/16m/s地滚球持续减速/停止、空阻/反弹耗能、5/10/30米传球到达预测、30米高球与有限触球/38m/s保护。沿用完整检查、确定性/检查点恢复、完整赛季、API及备份验收，最终结果见发布记录。

隔离实测修正后8m/s在1秒后约6.65m/s、约31.17m后停止；30m/s空中球1秒后水平约21.20m/s；2m落下第一反弹约0.55m。它们是统一干燥草地模型输出，不是球场认证。开发中3场短场抽样未见异常超速。

最终代码完整5400秒、seed42样本见[原始测量](calibration/physical-v061-full-seed42.json)：比分1:0、传球528/397、完成417/291，5Hz区间峰值球员8.252m/s（29.7km/h）、足球31.256m/s（112.5km/h），零超阈值采样。报告记录的瞬时球员峰值8.22m/s，与厘米量化区间峰值有小幅采样误差；不能混用为精确同一口径。球员活球采样均速2.169m/s、冲刺职责约6.1%，不是持续最高速。旧基线见[0.6.0三场180秒](calibration/physical-v060-before-180s.json)。诊断可运行`node tests/tools/audit-physical-motion.mjs --duration=5400 --seed=42`；这是可选诊断，不改变现有检查阶段。原0.6.0百场结果属于旧引擎，不作为0.6.1平衡拟合证明。

尚无风雨、草皮差异、马格努斯弯曲、真实骨骼/伤病；草地切向作用为显式阻力近似，不能宣称完全复现现实足球物理。

新引擎`0.6.1-physical-motion`、参数`physical-motion-1`；事件3、49值/5Hz、JSON3和SQLite表3不变。旧报告、球员档案与轨迹不重算。先让旧任务结算再升级；旧检查点只能用原引擎恢复，不能按新阻力重抽。完整备份先离机验证，回滚先保留最新完整快照。流程除上述用户批准两项外保持不变。
