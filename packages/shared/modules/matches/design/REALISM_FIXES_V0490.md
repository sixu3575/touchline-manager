# 传球误差、射门决策价值与门将触及（0.49.0-pass-keeper）

承接[0.48真实对阵修复](REALISM_FIXES_V0480.md)，原始汇总见[REALISM_FIXES_V0490_RESULTS.json](REALISM_FIXES_V0490_RESULTS.json)。原则不变：只改机制本身，不设射门、进球、比分或传球成功率配额。

**发布说明**：用户在得知本版场均总进球5.2（现实2.86）、强方射门偏多后，明确要求部署本版到生产以便在游戏中实测。这不改变以后的发布或拟真门槛。

## 诊断

1. **传球太准**：实际出脚误差为`(1−质量/100)×(0.28+0.025×距离)`的均匀分布，60档20米传球最多偏约±0.3米（最初批准的设计约0.68米）；压力、横向跑动、来球速度都不影响出脚。传球成功率在无压迫与贴身压迫下几乎相同（92.8%/92.2%）。
2. **射门决策读取了被压低的报告xG**：0.18起设计注明“几何机会值用于决策、校准xG只作报告”，后续“calibrate shot selection”提交把决策改为读取校准xG（×e^0.9压低约2.5倍），远射再乘一次个人精度折扣，弱队在禁区外几乎不射门。
3. **门将触及过大**：扑救身体横移上限是跑动极速（约7m/s，生物力学实测约3.5～4.5m/s）；手部是半径0.35米的球体并可伸出1.46米，指尖可达身体外约1.9米（现实约1.3米）。12～16米射正被扑出约93%，20～25米射门进球0%。

## 修改

| 位置 | 机制 |
| --- | --- |
| `decisions.mjs passDispersion/passContext` | 传球横向误差`0.15+距离×(0.012+0.05×(1−Q)+0.09×压力+0.006×横向跑速+来球相对速度×(0.003+0.006×(1−Q)))`，力度误差`0.15+距离×(0.03+0.08×(1−Q)+0.08×压力+0.005×来球相对速度)`，三角分布；压力项与射门同一扰动量级；不限制出界 |
| `decisions.mjs shotCandidate`、`shot-window.mjs` | 射门决策回到未校准机会值×个人精度修正；校准xG只作统计 |
| `goalkeeping.mjs`、`physics.mjs`、`simulation.mjs` | 扑救身体横移速度上限`3.2+0.012×灵活+0.006×单刀`；手部伸展`0.25+0.004×单刀+0.37×身高×倾侧`，接触半径0.15米；实际扑救与射手读取共用 |

## 已知问题（未解决）

**禁区防守**：强方38%的射门时射手与球门间没有外场防守者（现实约5～8%），射门时禁区内平均仅3.6名防守者；禁区内射门约70%来自连续带球。此前被压低的射门价值掩盖了这一问题，本版射门价值如实后直接表现为强方射门与进球偏多。短传仍约95%成功（接球者可修正1米级偏差）。下一步应修正防守者对禁区内持球人的封堵与上抢。
