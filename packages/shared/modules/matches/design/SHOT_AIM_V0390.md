# 0.39.0 射门落点的门线几何修正

之前射门目标放在球门线后方 1.5 米。物理规则判定进球的时刻则是足球整体刚刚越过门线：球心必须越过门线一个球半径。两者目标平面不一致。斜角射门在球飞向门后目标时，会先在更靠近射手的一点穿过门线；射门角度越窄，提前穿线造成的横向落点偏差越明显。因此名义瞄准点在两门柱之间，实际整球过线位置仍可能从门柱外侧经过。

0.39.0将目标平面移至门线外 `BALL_MOTION.radius + 0.05m`。进攻方向由 `direction` 决定，目标横坐标与 `goalCrossing` 的整球过线判定一致。球员瞄准的横向位置、远射选择、射门候选评分和出脚频率没有改变；终结、远射、力量、压力、距离、角度与身体速度仍决定落点误差和球路。进球、射正与扑救继续由实际足球轨迹、球门边界及门将/防守触球决定，xG 仍只是机会估值。

新增物理回归在两侧进攻方向、左右斜角共四种近距离场景生成真实射门冲量并推进 Rapier，验证整球均能从门柱内侧通过；同时保留原有球门边界、射门选择及能力作用测试。此项修复不重算已保存赛果或历史回放。
