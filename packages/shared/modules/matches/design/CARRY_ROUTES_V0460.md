# 0.46 多人带球路线风险

用户要求：完善“眼下能射、继续前进将遭两人拦截”的选择，普通盘带球员要能识别多层防线，同时保留高手突破和开放通道推进。实现只修改带球候选估值，**远射候选得分、真实抢断/触球/球速/进球物理不变**。候选引擎`0.46.0-carry-routes` / 参数`carry-routes-1`；无新属性、依赖或存档迁移，历史比赛不重算。

## 原实现的问题

0.45沿四个位置估计对手能否拦抢，最后只取最危险防守者的单次风险，再对其他协防者每人固定扣0.14；保球估值最低被限制为0.12。因此第二道防线没有独立的技术/时机对抗，早晚不同的拦截也被当成同类协防。能力很差的连续突破仍可能得到同样的12%底值。

新实现由`carry-route.mjs`负责纯估计，`carrying.mjs`继续生成前进/横移/回撤/边路路线并与传球、等待、射门比较。真实物理世界从不读取估计结果来直接判过人或丢球。

## 数学与实际能力消费者

每条路线在0%、20%、40%、65%、100%采样。持球者到各点的时间预先算一次；每名有效、唯一ID的防守者比较所有采样点，只保留最具威胁的接触窗口。同一人不因五个采样点变成五次独立抢断。双方到达使用原`arrivalTime`，含当前速度方向、加速、转向制动、反应、体能和短时冲刺恢复。

对窗口j，持球者到达时间a，对手到达时间b；对手实际可挑战时间取`max(b, tackleAt−当前时间)`。暴露估计为`clamp((a+0.35−b)/1.1,0,1)/(1+0.12a)`，取五点最大者。保留原4米内近身压迫补充`0.6×clamp((4−当前距离)/4,0,1)`，并按抢断恢复可用性缩放；补充只合入该人的一次暴露，不能再追加一次遭遇。

协助只来自代表性接触窗口在**3米、0.8秒内**重叠的人。两种接近度均线性衰减到零，再乘对手暴露与其`(预判+防守站位+团队配合)/300`，合成连续协防估计；后到的第二道防线不是瞬时协助。原`duelProbability`对协防最多2人的边际收益限制保持，与实际对抗共用函数，不再额外按人数固定扣分。

每个窗口的技术对抗沿原动作质量：盘带65%/灵活20%/平衡15%，对抢断70%/平衡20%/力量10%；惯用脚、镇定缓解压力及现有疲劳修正仍参与。接触条件下的抢断优势由共用`duelProbability`与先到优势、时空协防计算。**条件丢球估计为该窗口暴露×对抗失败概率**；沿每名防守者累乘`1−条件丢球估计`得到整段存活，不声称这些是由现实数据拟合的独立事件概率。

带球最终成功估计为`0.97×整段存活×(1−原越线风险)`；原越线风险仍由边界感知、制动与盘带决定。0.97是保留的无压控球估计基准，不是实际每次触球抽3%失误。取消原0.12最低保球值；没有增加射门/过人次数目标或比分上下限。原战术与个人倾向、可利用空间、后续射门/接应、丢球代价仍共同决定动作。

## 观察边界与局限

- 只读当前位置、速度、能力、体能和恢复状态；不读其他AI的隐藏目标或未来随机数。输入顺序变化或重复防守者不会重复加风险，罚下/来不及恢复/无法到达者不构成虚假遭遇。
- 五点采样、代表性窗口和条件存活是短程候选近似，不是另建未来物理世界；尚未完整推演防守者在每次失败抢断后的新轨迹、持球者中途再决策和诱导防守。未来射门空间仍沿0.45的可见速度外推，不能声称已解决所有等待/预判问题。
- 不规定面对两人必须远射；射门路线也可能被封堵，更好的传球、侧移或回撤均可胜出。盘带越强、对手越弱/越迟到，整段突破越有价值。不能把“横移摆脱”与“向前穿过两人”合并统计来宣称前冲没有减少。
- 无公开调试字段，`encounters`仅在本次函数局部使用，不保存到球员、检查点或玩家DTO；真实事件、抢断/过人统计及评分规则不改。

## 局部验证

新增六项回归，连同既有智能/跑位/战术共55项通过：两方向双防线、单人不重复计数/顺序不敏感、个人盘带与对手抢断分层、同时协防与后续防线区分、协防阅读能力、抢断恢复/罚下/不可达排除、输入不可变，以及100种子实际射门/前带/逃离选择。高盘带仍能突破弱单防；已有完全开放通道与明确射门/传球测试保持。

固定局部场景：24米中央、远射85/终结85、其他条件相同，仅改盘带；两名65能力防守者分别在x84/z33和x90/z35，球在x81/z34。直线路线最终保球估计由0.45的低盘带0.120/高盘带0.232变为0.46的0.048/0.202；不是实际比赛成功率。100种子中低盘带选择射门48次、回撤19次、等待33次，未向前穿过两层；高盘带也会选择侧移，不强制突破。

另一个单防场景（防守者x86/z33）中，盘带35的前进58/100，高盘带95为100/100；无人挡路时三种盘带水平均100/100前进。这些特定场景只能验证方向，不代表全场比例。
