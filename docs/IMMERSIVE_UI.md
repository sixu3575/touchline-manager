## 更衣室

每柜含稳定ID头像、真实号码球衣、姓名/位置/年龄、公开能力及体力/首发小牌；点柜打开原档案，六维图、细项区间、性格和生活信息保留。教练观察与进修收进教练夹板。

桌面每排7柜，≤700px手机每排3柜，上一排/下一排访问全队。能力、号码、位置、年龄、体力、进球、出场、轮薪、首发及姓名排序均可使用；能力未知值始终最后，不修改原数组或存档。筛选、排序和屏幕变化回到第一排。用28人和3/7柜检查不遗漏、不重复，收缩筛选结果不滞留空页。

## 报纸、数据屏与录像

体育报只排版已有真实数据。速报含紧凑积分、实际战绩与最近战况；完整积分保留近三场/名次变化/下一轮对手，放进可展开的完整积分。赛历保留14轮与每轮四场战报，他队没有回放入口。城市杯开放/淘汰条件和新赛季动作沿用原实现。

大屏复用原会话隔离的只读汇总接口，保留所有榜单、并列排名、覆盖率/缺失数据说明、加载/失败/刷新。只显示已结算联赛，屏幕内部可滚动并固定表头，长榜单不撑高整台电视。

录像带标签打开原MatchReport，播放键打开原Replay；点球、双方首发平均能力继续显示，canReplay=false无播放键。旧回放读取保存轨迹和比赛年龄，不重新计算。
