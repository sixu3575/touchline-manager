# 球员模型与扩展契约

新的比赛细项作用和数学方案见 [待审批设计](PLAYER_MATCH_DESIGN.md)，尚未启用；本文件继续描述当前 0.2.0 实现。

所有球员为虚构人物。当前属性模型版本 2，能力范围 1–100、最多一位小数；性格和状态为 0–100。国籍和姓名用于身份表现，国籍不改变能力、成长或随机事件概率。

## 能力

| 分组    | 细项                                                         |
| ------- | ------------------------------------------------------------ |
| 技术 10 | 终结、远射、传球、停球、盘带、传中、抢断、盯人、头球、定位球 |
| 意识 8  | 视野、决策、镇定、防守站位、无球跑动、预判、团队配合、专注   |
| 身体 6  | 爆发力、冲刺速度、灵活、平衡、力量、耐力                     |
| 门将 6  | 反应、手型与接球、单刀处理、制空、指挥防线、出球             |

attributes 是唯一细项来源。skills 六项为派生兼容缓存：速度来自爆发/冲刺；射门来自终结/远射/镇定；传球来自传球/视野/决策；防守来自抢断/盯人/站位；耐力直接读取耐力；门将来自反应/接球/单刀/制空/指挥。评级和当前简化比赛引擎使用这些摘要；停球、盘带、传中、头球、定位球、跑动、预判、配合、专注、灵活、平衡、力量和门将出球已建模和可培养，但尚无单独比赛事件权重，不宣称所有细项已经独立影响赛果。后续比赛模块可扩展公开契约，不直接导入球员内部文件。

## 身份与时间

身份含 birthDate、age、nationality（ISO 两字母代码）、preferredFoot、weakFoot、heightCm；新球员按国家姓名池生成，含 12 国。初始游戏日 2026-07-01，联赛每轮推进七天，下赛季跳到下一年 7 月 1 日。age 由生日与游戏日推导，包括市场球员；不会随实际电脑日期改变。新成年球员 19–34 岁，青年 16–18 岁；现有年龄完整保留。身高、惯用脚、逆足当前为档案数据，未附加隐藏比赛加成。

## 人格、状态和扩展点

- personality：职业态度、进取心、忠诚倾向、情绪稳定、领导力、社交意愿、适应能力、抗挫能力。长期倾向不因一场比赛改写；高分代表倾向更强，不是道德优劣。标签由阈值派生，不另存一份容易失配的数据。
- wellbeing：士气、信心、归属感，比赛结算按出场与结果更新。当前不影响比赛能力，不自动触发事件。
- publicProfile：表达风格、两项兴趣、关注度。关注度随出场胜利/进球增长；当前无商品或商业收入。
- 生涯统计 goals/assists/apps/form 与工资、价格保持兼容。未实现助攻事件时 assists 不伪造增长。

已接入：年龄系数（≤21 岁 1.2、22–29 岁 1、≥30 岁 0.65）与职业态度系数（0.75 + professionalism/200）共同影响训练增量；门将有专项；潜力以下增长，不降低已高于潜力的旧属性。

后续互动、随机事件和粉丝经济应只通过 players 模块新增受限领域操作，分别读取稳定人格与短期状态，不直接跨模块改球员 JSON。当前不预设关系网、伤病、续约、事件总线或粉丝消费规则，避免把未实现系统写成已经可玩。

## 迁移

见 DATA.md。旧档的细项由六项能力确定性展开，保持原评级与六项摘要；个性由存档 seed + player.id 派生。旧姓名与年龄不改；国籍和生日是虚构身份补全。旧回放保持原样。
