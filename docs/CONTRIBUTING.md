# 协作

统一执行 AGENTS.md。首次初始化直接 main；以后每个任务一个短期分支，一个工作区一个写入者。提交解释行为变化，不提交密钥、存档、备份、dist 或 node_modules。

```sh
npm ci
npm run check
```

CI 在 Node 22 与 24 上运行相同检查。新增行为提供可观察的验证；修改图形界面需要桌面/窄屏检查。PR 描述问题、改后行为、验证结果、数据风险与回滚方式。没有成功部署和公网验证不能声称上线。

2026-10-17用户批准仅两项调整：测试文件固定最多4个并行；CI在pull_request及main的push触发，功能分支不再同时重复触发push/PR两份矩阵。全部测试/完整赛季、Node22/24、npm run check、PR审查及发布备份不变。其他流程改动仍须另行批准。

提交前同步相关玩法/架构/数据文档与 CHANGELOG。涉及生产数据的任务必须区分代码、配置和状态迁移，禁止用清空存档修复代码问题。

本次归档另获用户明确的单次纯文档验证例外，采用渲染、源码/链接、模块测试、类型与构建检查，复用已发布0.6.1的完整比赛回归；重复完整检查主动停止，CI命令/配置不改。具体授权见根AGENTS，不外推到以后任务或另案提速方案。
