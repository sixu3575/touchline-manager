# TOUCHLINE · Ink 美术规范

原创运动漫画方向，参考 Tape to Tape 的夸张运动人物、墨线与复古配色，不使用其角色、贴图、标志或截图。头像为本项目绘制的SVG/CSS，早期AI人物母稿只作参考。场景式界面的院子、更衣室和编辑桌则使用内置image_gen生成的原创插画，真实数据与操作叠加于独立HTML层，见[场景交互规范](IMMERSIVE_UI.md)。

2026-10-27场景重绘cartoon-scenes-3以实际头像联系表为墨线基准，造型上进一步放大运动喜剧：球鞋房屋、口哨烟囱、怪兽轮胎车、巨型计算器/金靴、裁判旗天线与大灯罩，以明显的不对称、挤压、拉伸和尺寸错位表达笑点。采用深墨#18232a外轮廓、平涂蓝绿/芥末/米白、硬边阴影、歪屋顶和大比例道具。减少细碎纹理、真实反光与材质光照；柜体和路牌不加木纹或柔和内阴影，报纸不加颗粒纹理。后续新素材须与运行时头像并排核对，不以独立背景画的精细程度代替风格一致性。头像touchline-ink-1与三阶段生涯渲染保持固定。

## 界面

`packages/client/src/ink-theme.css` 集中维护全站主题，基础布局留在 style.css 和模块样式。深墨 #1c3037、蓝绿 #315e62、芥末黄 #e8b854、暖纸 #fbf6e7。硬阴影、轻微倾斜的人物卡与原创球场插画表达搞怪球会气质；数据表和比赛按钮保持清晰。无字体下载、远程图片、动画滤镜或新运行依赖。

公共 `StadiumIllustration` 位于 components/ui.tsx，主场页保留。新总览使用可点击院子，所有路牌数据读取现有公开状态，画面不推导能力、伤情或赛果。

## 球员身份与生涯

基础身份版本 `touchline-ink-1` 固定 ID/散列/零件顺序/数量，避免更新时换脸。生涯渲染版本 `touchline-career-1` 独立于身份；不写入存档，不改生日或成长逻辑。

| 当前公开年龄 | 形象     | 美术处理                                           |
| ------------ | -------- | -------------------------------------------------- |
| ≤18          | 青训     | 柔和短脸、稍大的眼部、较小鼻头、去成年胡须与细纹   |
| 19–29        | 青年     | 基础成人配方                                       |
| ≥30          | 中年     | 保留脸型/发型/五官，增加克制的眼角、嘴角与下颌线条 |
| 缺失或无效   | 中性成年 | 不猜年龄、不借用现役年龄                           |

名单、球探、档案、阵型板按 Player.age；历史评分和观赛选人按对应 report.snapshots 的球员年龄。历史报告不重算、不修改。头发和肤色不是国籍、能力或性格的代理，30岁不自动白头或秃顶。

成年基础配方有 34,836,480 种理论组合，不含球衣/底色；相似轮廓和哈希碰撞意味着不能承诺这么多个视觉唯一人物。青训隐藏胡须等成年细节，组合数更低；三个年龄阶段是同一身份的演变，不把独立人物容量乘三。

## 资源与性能

客户端按可见球员 ID 和年龄生成 SVG data URL，React memo 复用；服务器继续只提供已有公开身份/年龄，无图片生成服务、头像数据库列或迁移。现机单进程/单 worker/512MiB 限额不变。头像的渲染成本在浏览器，不能用本机纯字符串生成速度声称移动设备或服务器并发容量。

离线实验室与零件/三阶段样例由以下命令导出；它不是游戏菜单，也不暴露存档数据：

```sh
node packages/client/src/modules/players/portraits/export-assets.mjs dist/portrait-assets
```

验证覆盖固定配方、18/19/29/30边界、历史年龄缺失、换衣不换脸、10000个种子的分布及 SVG 输入安全。普通 UI 发布按现有分层检查运行，不为美术改动计算真实比赛或赛季；发布前后备份与数据指纹比较仍必需。
